# O50 — Сайт встановлюється на телефон як застосунок

**Стан:** 0 / 5 прийнято — KR50.1–50.4 реалізовано локально 2026-10-10, очікують production і перевірки на пристроях · **Відкрито** 2026-10-08 за словами власника:
«перетворити сайт на ідеальний PWA, щоб я міг легко завантажити його і на Android, і на iOS
(не для маркетплейсів)».

## Навіщо

~2/3 гравців сидять лише з телефона ([KR22.6](../o22-content-static-user-live/kr22.6-offline-pers.md)).
Лист персонажа вже працює офлайн, і правки доїжджають самі. Але відкривати його досі доводиться
з браузера. Іконка на домашньому екрані, запуск на весь екран без адресного рядка й звичний
«застосунок» замість вкладки — це останній крок. Офлайн-механізм для нього вже готовий.

Пропозиція встановлення в інтерфейсі призначена лише для телефонів і планшетів. На десктопі немає ні банера, ні пункту встановлення в меню; вузьке вікно або сенсорний екран Windows не змінюють цього. iPad з desktop user agent підтриманий.

Магазини застосунків поза межами цілі: ні Google Play (TWA), ні App Store (обгортка).
Встановлення — з браузера, на тих самих адресах і з тим самим деплоєм.

## Еталонні пристрої

| Пристрій | Браузер | Екран | Особливості |
|---|---|---|---|
| **Google Pixel 8** | Chrome | 412×915 CSS px, DPR 2.625 | жестова навігація, системний «Назад», WebAPK |
| **iPhone 14 Pro Max** | Safari (і Chrome на iOS) | 430×932 pt, @3x, 1290×2796 px | Dynamic Island, без системного «Назад», жест від лівого краю |

Версію ОС і браузера записуй у журнал кожної перевірки: поведінка встановлення змінюється між
версіями. З iOS 26 сайт, доданий на початковий екран, за замовчуванням відкривається як
вебзастосунок (перемикач «Open as Web App»).

## Виміряний стан (2026-10-08)

Продакшн, `curl` заголовків і `<head>` сторінки `/char/home`, плюс код.

**Вже є:**
- `public/manifest.json`: `display: standalone`, `start_url: /char/home`, `scope: /`,
  `lang: uk`, кольори `#020617`.
- `public/sw.js` з обробником `fetch`. Він кешує оболонку, сторінки, медіа й картки заклинань,
  а без мережі віддає збережену сторінку або `/offline` ([KR22.6](../o22-content-static-user-live/kr22.6-offline-pers.md)).
- Офлайн-черга правок листа, шлагбаум серверних дій без мережі, бейдж незбереженого.
- `viewport-fit=cover`; нижня навігація відступає на `env(safe-area-inset-bottom)`.

**Чого бракує:**

| Що | Стан | Наслідок |
|---|---|---|
| Іконки 192 і 512 px | єдина `purpose: any` — `logo.png` **494×500**, не квадрат | Chrome вимагає 192 і 512, тож повноцінне встановлення (WebAPK), найпевніше, не проходить. Підтвердити в DevTools → Application → Manifest → Installability |
| Maskable-іконка | немає | Android кладе прозоре фіолетове дерево в білий круг |
| `monochrome` | `dragon.png` — інший малюнок, ніж основна іконка | тематичні іконки Android показують дракона замість логотипа |
| `apple-touch-icon` | `/apple-touch-icon.png` → **404**, тегу немає | iOS бере на іконку знімок сторінки |
| `apple-mobile-web-app-*`, `theme-color` | немає жодного тегу | смуга статусу iOS і колір вікна Android — дефолтні, не темні |
| Заставка запуску iOS | немає `apple-touch-startup-image` | iOS не будує заставку з маніфесту — при старті порожній екран |
| `id`, `screenshots`, `shortcuts` у маніфесті | немає | без `screenshots` Chrome показує бідний діалог встановлення; немає швидких дій з довгого натиску |
| Кнопка «Встановити» | `beforeinstallprompt`, `display-mode`, `navigator.standalone` у коді не згадуються | гравець не дізнається, що сайт можна встановити; на iOS — тим паче |
| Оновлення у встановленому застосунку | `sw.js` віддається з `max-age=14400`; підказки «є нова версія» немає | у standalone немає кнопки перезавантаження й адресного рядка; iOS тримає застосунок у памʼяті днями |
| Верхня безпечна зона | `safe-area-inset-top` ніде не врахована | якщо смуга статусу прозора, шапки й модалки залазять під Dynamic Island |

**Неперевірене, що може зламатися лише у встановленому застосунку**:
- вхід через Google (редірект на `accounts.google.com` поза `scope`, One Tap);
- завантаження PDF листа (`PrintCharacterDialog` — blob + `a.download`);
- друк каталогів у новому вікні (`window.open(..., "_blank")`);
- зовнішні посилання;
- жест «Назад» з історією модалок.

Це перевіряється лише на пристрої (KR50.5).

## Критерій готовності

На **Pixel 8** гравець відкриває сайт у Chrome, тисне «Встановити застосунок» у меню сайту й
отримує системний діалог зі скриншотами. На домашньому екрані зʼявляється адаптивна іконка
без білого кола. Застосунок стартує на весь екран із темною смугою статусу, а довгий натиск на
іконку дає швидкі дії.

На **iPhone 14 Pro Max** гравець у Safari тисне те саме «Встановити застосунок» і бачить
покрокову підказку для Safari. Після «На початковий екран» маємо іконку-логотип, темну заставку
запуску й нічого під Dynamic Island.

Далі на обох пристроях у встановленому застосунку:
- гравець входить через Google;
- відкриває лист, знімає хіти й завантажує PDF;
- повертається «Назад» з модалки;
- без мережі відкриває той самий лист;
- після деплою отримує нову версію без перевстановлення.

Кнопка «Встановити» не показується всередині вже встановленого застосунку.

## Межі

- **Не робимо:**
  - публікацію в Google Play чи App Store (TWA, Capacitor, PWABuilder-пакети);
  - push-сповіщення;
  - `share_target`, обробники файлів і протоколів, значок на іконці (Badging API);
  - встановлення на десктоп як окрему ціль. Воно запрацює саме, але приймання — лише телефони.
- **Precache усього довідника наперед** лишається окремим KR з явною кнопкою, як записано в
  [KR22.6](../o22-content-static-user-live/kr22.6-offline-pers.md#7-чого-свідомо-не-робив). Ця
  ціль не змінює, що саме кешує воркер. Вона змінює лише те, як він оновлюється (KR50.4).
- Логіку офлайн-черги не чіпаємо ([Р29](../DECISIONS.md#р29)).
