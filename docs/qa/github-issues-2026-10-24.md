## Перевірка

- **15 файлів, 63 тести — пройшли** (`bun run test:no-db`, цільовий набір цієї партії).
- Цільові no-DB тести покривають ID-колізію та зміну вибору, походження 2024, fallback імені,
  назви/джерела заклинань, зміни review рівня, HP і стелі характеристик, URL-sync,
  налаштування, CR, aliases та TOC. Перші регресії review/HP падали на старому коді.
- TypeScript пройшов **в ізольованій копії**. У корені застарілі `.next` / `.next-owner`
  validators посилаються на відсутні сторінки; їх не змінювали й не видаляли.
- ESLint перевірених файлів без помилок; зайві імпорти `NameForm` прибрані.
  UI static check чистий; guard розміру/вкладеності/клонів відповідних компонентів без порушень.
- Живий локальний GET `/api/spells/selected` повернув 200 та правильні назви Fire Bolt,
  Guidance і Shield за реальними ID БД 2024; `Cache-Control: public, max-age=300`.
- Chromium 1280×900 та WebKit iPhone 375×812: review Людини-Воїна 2014 має «Оборона»;
  review Дворфа-Пройдисвіта 2024 має СПР 17, СТА 15, **11 HP**, мову й дві майстерності.
  Обидві редакції без горизонтального переповнення. Це перевірка review з чернеток,
  а не доказ повного створення цих двох персонажів.
- Обидва рушії: cold deep-link і reload `q=beholder`, з карткою й без неї, в обох редакціях;
  старий `creature=beholder-2024` працює. Перевірено недоступність кнопки для мультикласу
  із сумою рівнів 20 та локалізований прямий URL.
- В окремій browser-базі реально збережено й перезавантажено аркуші: Воїн 3→4,
  «Кухар», СТА 15→16 — preview **+12**, результат **40/40 HP**; Монах 1→2 зі Tough —
  preview **+9**, результат **21/21 HP**. Числа додатково звірені читанням локальної БД.
- Стандартний UI-probe на бестіарії, магічних предметах і правилах у двох рушіях, composite
  переглянутий. Залишаються старі 36px кнопки друку/дрібні бейджі та Google One Tap warnings
  на localhost; вони поза зміненими частинами. У scripted HP-проходах page errors не було.
