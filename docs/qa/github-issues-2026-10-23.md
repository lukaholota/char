# Розбір GitHub issues — 2026-10-23

Продовження: [локальні виправлення й перевірки 24.10](github-issues-2026-10-24.md).

Переглянуто всі **21 відкритий issue** репозиторію `lukaholota/char`, їхні описи й усі
коментарі через GitHub connector. Код перевірено локально на `main`, `566621cb`.
Робоче дерево перед розбором було чисте. Статуси й тексти issues у GitHub не змінювалися.

Це перевірка коду, файлових даних і вже опублікованих QA-доказів. Нового браузерного
прогону, перевірки прод-БД чи відповідності прод-деплою локальному HEAD не було.
«Підтверджено кодом» нижче не означає нового відтворення на production.

**Результат:** 16 issues мають підстави для виправлення в коді/даних або свіжий QA-доказ;
3 потребують уточнення сценарію чи очікування; 2 суперечать чинним рішенням власника.
Доказів критичної втрати даних у цьому наборі немає. Для багатьох проблем review QA
окремо підтвердив правильність збереженого аркуша.

## Перевірки цього розбору

`bun run test:no-db tests/components/levelup-hp-racial-bonus.test.tsx tests/components/creation-step-completion.test.tsx tests/components/glossary-term.test.tsx`

**3 файли, 15 тестів — пройшли.** URL бази навмисно недоступний; БД не читали й не змінювали.
Додатково Python прочитав вибрані generated JSON: два записи бехолдера, структурні
маркери назв істот, ID-колізії Воїна й label інструмента монаха. Вихідні дані не змінювалися.

Цей зелений прогін не спростовує issues: наявні тести не перевіряють назви/повноту review,
cantrip-only завершеність, вибір СТА у рисі, cold deep-link чи пояснення всіх доданків HP.
Реалізацій, сідів, комітів, пушів і деплоїв у межах цього розбору не було.
