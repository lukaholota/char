# KR52.2 — Стіни й двері

**Ціль:** [O52](README.md) · **Стан:** ⚪ не розпочато · **Залежить від:** [KR52.1](kr52.1-visibility-geometry.md) (тип `SightSegment`)

## Мета

Майстер позначає на мапі стіни й двері — пальцем на телефоні так само, як мишею. У грі він
відчиняє й зачиняє двері одним дотиком. Сам по собі цей KR гравцям нічого не показує: стіни
починають працювати в [KR52.3](kr52.3-light-vision.md).

## Схема

`db/changes/<дата>-game-scene-walls.sql`, лише додавання, до релізу:

```sql
CREATE TABLE public.game_scene_wall (
  game_scene_wall_id serial PRIMARY KEY,
  game_scene_id integer NOT NULL REFERENCES public.game_scene(game_scene_id) ON DELETE CASCADE,
  kind varchar(4) NOT NULL CHECK (kind IN ('wall', 'door')),
  is_open boolean NOT NULL DEFAULT false,
  -- [[x, y], ...] у частках мапи: стіна 2–40 точок, двері рівно 2.
  points jsonb NOT NULL CHECK (jsonb_typeof(points) = 'array'),
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX game_scene_wall_scene_idx ON public.game_scene_wall (game_scene_id);
```

Рядок на ламану, а не один JSON на сцену (як туман): двері перемикаються оновленням одного рядка,
а стіну редагують окремо від інших.

## Правила — `src/rules/game-walls.ts`

- `WALL_LIMITS = { segmentsPerScene: 400, pointsPerWall: 40, perSave: 60 }`.
- `parseWall(raw)`, `buildWallView(row)` — за зразком [game-drawings.ts](../../src/rules/game-drawings.ts);
  точки через `parseStrokePoints` / `toStoredPoints` з [map-strokes.ts](../../src/rules/map-strokes.ts).
- `countWallSegments(walls)` — для ліміту.
- `collectSightSegments(walls, aspect): SightSegment[]` — ламані у відрізки, відчинені двері пропускає.
- `snapWallPoint(point, frame, nearbyPoints)` — спершу до кінця наявної стіни в межах дотику, інакше
  `snapToHalfCell`; без сітки — лише до наявних кінців.
- `findWallIdsNearPoint` — через `isPointNearStroke`, для вибору дотиком.
- `buildSceneWallViews(rows, isGm)`: **гравцям ідуть лише зачинені стіни без `kind` і список дверей
  `{ id, at, isOpen }`** — так таємні двері не видно в даних як двері. Майстру — все.

## База й дії

Новий `src/server/db/game-scene-walls.ts` (у `game-scene-tools.ts` уже тісно), усе — лише майстер
(`findActiveGmSession`), у транзакції з `lockScene`, наприкінці `signalGameSession(…, "session")`:

- `saveSceneWalls(sessionId, userId, sceneId, walls[])` — ліміт відрізків рахується під замком;
- `changeSceneWall(…, wallId, points)` — рух вершин;
- `setSceneDoorOpen(…, wallId, isOpen)`;
- `removeSceneWalls(…, ids | "all")`.

Зміна мапи сцени видаляє стіни сцени — у тому самому місці
[game-scenes.ts](../../src/server/db/game-scenes.ts), де знімаються токени.

Дії в [game-scene-tools.ts](../../src/lib/actions/game-scene-tools.ts) — тонкі, розбір через правила.
`GameSessionView` отримує `walls` і `doors`.

## Інтерфейс

Новий інструмент `"walls"` у `MapTool` і [MapToolbar.tsx](../../src/components/games/MapToolbar.tsx),
лише для майстра. Хук `use-map-walls.ts` за зразком
[use-map-drawings.ts](../../src/components/games/use-map-drawings.ts), шар `MapWallsLayer` у SVG.

| Режим панелі | Жест |
|---|---|
| Стіна | Кожен дотик ставить вершину ламаної з прилипанням; «Готово» завершує, дотик у першу вершину замикає кімнату |
| Кімната | Протягнути рамку — чотири стіни (та сама рамка, що в тумані: `toRect`) |
| Двері | Два дотики: кінці дверей. Якщо обидва лежать на одній стіні — стіна розрізається, двері стають між частинами |
| Правка | Дотик по стіні вибирає її: ручки `MapHandle` на вершинах, «Видалити» |

- Мапу під час малювання рухають двома пальцями, як в інших інструментах (`gesture` у `useMapViewport`).
- Скасування — через `rememberUndo` / `pushUndoStep` ([map-history.ts](../../src/components/games/map-history.ts)).
- Оптимістичний показ — `sendOptimistic`, як малюнки.
- Майстер бачить стіни, коли відкрито «Стіни» або «Світло»; двері — завжди, значком на середині
  відрізка. Поза інструментами дотик по значку перемикає двері (перевірка влучання — там само, де
  `openTappedArea` у MapBoard).
- Стани: порожньо («Позначте стіни — гравці бачитимуть лише те, що бачать герої»), ліміт
  («Забагато стін на сцені»), помилка збереження — тост і відкат.

## Тести

- `tests/rules/game-walls.test.ts` — розбір, ліміти, прилипання, розрізання стіни дверима, вигляд для гравця.
- `tests/db/game-map.test.ts` — гравець не може зберегти стіну; ліміт; нова мапа прибирає стіни;
  гравець не отримує `kind` і відчинених дверей у відрізках.
- `tests/components/game-room-map.test.tsx` — інструмент видно лише майстру; двері перемикаються.
- Браузер на копії: 375 WebKit — намалювати кімнату з дверима пальцем; 1280 Chromium.

## Приймання

Майстер на телефоні за хвилину обводить кімнату з двома дверима; стіни переживають перезавантаження;
гравець у DevTools не бачить, які відрізки — двері.

## Поза KR

Зупинка токенів гравців стінами (вона в [KR52.3](kr52.3-light-vision.md#стіни-зупиняють-токени-гравців)), вікна, односторонні стіни, копіювання стін між сценами, авторозпізнавання.
