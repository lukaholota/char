# KR52.4 — Обʼєкти на мапі

**Ціль:** [O52](README.md) · **Стан:** ⚪ не розпочато · **Залежить від:** — (не потребує стін і світла)

## Мета

Майстер кладе на мапу окремі картинки — стіл, скриню, двері, дерево, пастку, — рухає, крутить і
масштабує їх, а деякі тримає схованими, доки не настане час. Це не істота: без хітів, ініціативи
й статблоку.

## Звідки графіка

Питання Кима «де брати графіку, чи дозволяти завантажувати свою»
— власник погодив такий план (Р69):

1. **Свої завантаження — у першій версії.** Наявна бібліотека майстра `user_token_image`
   (ліміт 60 зображень, завантаження в R2, стиснення) уже вміє все потрібне; обʼєкт просто
   посилається на її `image_key`. Прозорий фон зберігається (webp).
2. **Базовий набір — другим кроком**, за зразком «Базових мап»
   ([map-library-catalog.ts](../../src/lib/refs/map-library-catalog.ts), `scripts/add-map-library.ts`):
   статичний каталог `library/objects/<slug>`, не в клієнтському бандлі. Набір обирає власник;
   ліцензію кожного кандидата (Forgotten Adventures, 2-Minute Tabletop, Kenney) треба прочитати
   перед завантаженням — у цьому дослідженні вони **не перевірялись**.

## Схема

```sql
CREATE TABLE public.game_scene_object (
  game_scene_object_id serial PRIMARY KEY,
  game_scene_id integer NOT NULL REFERENCES public.game_scene(game_scene_id) ON DELETE CASCADE,
  image_key varchar(200) NOT NULL,
  name varchar(40),
  x real NOT NULL CHECK (x BETWEEN 0 AND 1),
  y real NOT NULL CHECK (y BETWEEN 0 AND 1),
  -- Ширина в клітинках; без сітки — у сотих ширини мапи.
  width_cells real NOT NULL DEFAULT 1 CHECK (width_cells BETWEEN 0.25 AND 40),
  rotation smallint NOT NULL DEFAULT 0 CHECK (rotation BETWEEN 0 AND 359),
  is_hidden boolean NOT NULL DEFAULT false,
  sort_order integer NOT NULL DEFAULT 0,
  created_at timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX game_scene_object_scene_idx ON public.game_scene_object (game_scene_id);
```

`image_key` без зовнішнього ключа: він може вказувати і на `user_token_image`, і на базовий набір.
Видалення зображення з бібліотеки майстра, яке стоїть на сцені, — або заборонити з поясненням,
або прибрати обʼєкти; перевірити, як це вже зроблено для `custom_image_key` істот, і зробити так само.

## Правила, база, дії

- `src/rules/game-objects.ts`: `OBJECT_LIMITS = { perScene: 100 }`, `parseObjectPlacement`,
  `buildSceneObjectViews(rows, isGm)` — **сховані обʼєкти гравцям не віддаються** (фільтр у вигляді,
  як істоти поза мапою в `buildMapCreatureViews`). Поворот і розмір — наявні межі з
  [token-transform.ts](../../src/rules/token-transform.ts).
- `src/server/db/game-scene-objects.ts`: `addSceneObject`, `changeSceneObject` (позиція, розмір,
  поворот, назва, схованість, порядок), `removeSceneObjects` — лише майстер, з `lockScene` і лімітом.
- Нова мапа сцени видаляє обʼєкти сцени.

## Інтерфейс

- Шар `<img>` над картинкою мапи, сіткою й областями, **під** істотами, темрявою й героями. Обʼєкт —
  частина мапи: масштабується разом із нею (без `COUNTER_ZOOM`), розмір `width_cells × cellPx`.
- Інструмент `"objects"` (майстер). Поки він закритий, обʼєкти не ловлять дотиків — гра не чіпляється
  за меблі. Відкритий: «Додати» відкриває бібліотеку зображень (той самий вибір, що в
  [CreatureImageSection.tsx](../../src/components/games/CreatureImageSection.tsx)), новий обʼєкт стає
  в центр екрана; дотик вибирає, перетягування рухає (`useTokenDrag`), рамка з ручками повороту й
  розміру — з [TokenTransformControls.tsx](../../src/components/games/TokenTransformControls.tsx).
- Панель вибраного: назва, «Сховати від гравців» (майстер бачить схований напівпрозорим),
  «Наперед / Назад», «Копія», «Видалити». Скасування — `pushUndoStep`.
- Під темрявою обʼєкти ховаються самі, бо шар темряви вище.
- `alt` — назва обʼєкта або порожній для декору.

- Браузер: 375 WebKit — додати, повернути, сховати; гравець у другій сесії не бачить схованого.

## Приймання

Майстер із телефона ставить скриню, ховає її, показує в потрібний момент; гравці бачать її без
перезавантаження. Схованого обʼєкта немає у відповіді сервера гравцю.

## Поза KR

Обʼєкти, що блокують зір; обʼєкти, які рухають гравці; стани й хіти обʼєктів; анімовані обʼєкти;
редактор приміщень із плиток.
