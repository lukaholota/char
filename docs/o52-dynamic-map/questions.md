# O52 — питання власнику

Відкритих питань немає. Відповіді власника від 2026-11-10 записані в [Р69](../DECISIONS.md).

| № | Питання | Відповідь власника |
|---|---|---|
| 1 | Спільний зір партії | Так: гравець бачить очима всіх героїв партії |
| 2 | Хто відчиняє двері | Лише майстер |
| 3 | Стіни й рух токенів | «Як у конкурентів»: стіни й зачинені двері зупиняють токени гравців, майстер проходить. План — у [KR52.3](kr52.3-light-vision.md#стіни-зупиняють-токени-гравців) |
| 4 | Графіка обʼєктів | Перша версія — завантаження майстра через наявну бібліотеку зображень; базовий набір пізніше. Ліміт бібліотеки (60) поки не чіпаємо — підняти, якщо майстри в нього впруться |
| 5 | Серверне приховування істот у темряві | Не робимо: лишається модель Р63, ховає браузер |
| 6 | Плавне відступання темряви | Плавно: коли картину змінив хтось інший, темрява переходить за ~180 мс |
| 7 | Ваншот у Roll20 з Кимом | Без відповіді; не блокує |

## Як стіни зупиняють рух у конкурентів

Перевірено 2026-11-10 за доками й форумами, самі продукти не запускались.

| | Гравець | Майстер |
|---|---|---|
| Roll20 | Стіна зупиняє токен, якщо на сторінці ввімкнено «Restrict Movement», і лише токени із зором | Проходить крізь стіни |
| Foundry | Стіна зупиняє завжди; окремі типи стін пропускають рух | Проходить (Unconstrained Movement) |
| Owlbear Rodeo | Стіна зупиняє в реальному часі: щоб гравець випадково не зайшов у ще не відкриту кімнату | Перемикач Wall Pass |

Причина стосується й нас: темрява йде за токеном під пальцем, тож без зупинки гравець протягне
героя крізь стіну й побачить сусідню кімнату, навіть не відпустивши токен.
