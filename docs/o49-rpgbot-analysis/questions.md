# O49 — Залежності та рекомендовані стартові рішення

**2026-09-28.** Продуктовий обсяг визначений власником у поточній розмові.
План не потребує повторного погодження кожного технічного кроку.

| Пункт | Стартове рішення | Статус |
|---|---|---|
| Повний вихідний корпус | Надані для роботи тексти/експорт або підтверджений дозвіл RPGbot на використання й переклад | Залежність повнотекстового імпорту; джерело поки не надано |

| Власні оцінки | Зберегти оцінки й аргументи RPGbot; editorial notes явні | Вимога власника |
| Повнота | Весь character optimization обох редакцій, не лише subclasses | Вимога власника |
| Перша інтеграція | Підкласи в каталозі та конструкторі; контракт готовий до інших сутностей | Обсяг O49 |
| Конструктор за запропонованими варіантами | Дерево від класу, вхід зі статті, налаштування → summary/ім’я → реальний персонаж | Вимога власника; KR49.8–49.10, входить у приймання O49 |

| Повний аналіз із модалки | Та сама модалка, повернення до підкласу; canonical article доступна окремо | Рекомендований default |

позначити KR49.3/O49 завершеними за самими метаданими або переказами.
