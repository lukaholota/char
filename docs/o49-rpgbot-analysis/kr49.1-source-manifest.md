**Вхід:** [inventory.json](../research/rpgbot/inventory.json), [scope O49](README.md#межі-корпусу).
**Результат:** [manifest](../../data/rpgbot/manifest.json), [звіт покриття](../../data/rpgbot/manifest.coverage.md), [структуровані counts і review](../../data/rpgbot/manifest.coverage.json), [tooling](../research/rpgbot/MANIFEST-TOOLING.md). Це ще не повний корпус текстів.

## Реалізація

1. Нормалізувати 479 кандидатів усередині коренів та 18 зовнішніх посилань.
   Перевірити requested/final/canonical URL, HTTP status, aliases та дублікати.
2. Визначити included/excluded/review і причину для кожного запису.
   Оглядові індекси відділити від самостійних гайдів; не втратити їхню аналітику.
3. Доповнити sitemap обходом посилань у змістовній частині включених сторінок.
   Зовнішні корені мають allowlist; не йти в новини/подкасти/інші системи.
   Обмежити crawl rate, дотримуватися актуального robots, не обходити login/антибот.
4. Підтвердити редакцію за explicit article notice; URL лишається evidence-кандидатом.
   Виявити cross-edition links, сторонніх видавців та статті без наших entity matches.
5. За наявності дозволеного повнотекстового джерела виміряти слова, sections, tables,
   rating blocks і пов’язані статті; до отримання корпусу позначити ці поля unknown.
   Не підміняти кількість слів довжиною HTML із рекламою.
