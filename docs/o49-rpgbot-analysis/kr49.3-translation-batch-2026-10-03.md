# KR49.3 — друга партія: 20 аркушів (2026-10-03)

Власник дав команду перекладати двадцять аркушів, що лишалися порожніми після контролю якості.
Усі чернетки приватні: `unpublished`, у git не додавалися, нічого не опубліковано.

## Що зроблено

- 20 аркушів (Чародій-підкласи ×8, Винахідник ×5, Слідопит ×3, Монах 2024 ×4): ≈2667 порожніх полів переведено перекладачами-субагентами за `BRIEF.md` і новим `BRIEF_ADDENDUM_2026-10-03.md`; ще 148 фрагментів підтягнув `reuse_all.py` з уже готових сторінок.
- Довгі сторінки ділено на частини: Монах 2024 (3), Слідопит, Слідопит-підкласи, Винахідник, раси Винахідника (по 2); решту переклав один агент на аркуш.
- Перевірки на кожній сторінці: `check_tr`, `missing_keys`, `qc_check` (0 помилок, 0 підказок CANON на всіх 20), якісний скан `w.py`.
  Лінтер маркерів тепер ловить і маркер без охоплених слів (`RAW` після дужки, `1{{Natural 1}}`).
- Покращено конвеєр: `w.py` приймає коди книг (ERLW та ін.) і сам вирішує порожні рядки таблиць, додаткові рядки заголовків;
  `check_tr.py` прибирає свій тимчасовий файл (він ламав тест апострофів).
- `translation.coverage.json` оновлено: 200 неопублікованих чернеток (було 180). Індекси сайту порожні, бо чернетки не опубліковано.
