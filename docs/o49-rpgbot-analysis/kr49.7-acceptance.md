# KR49.7 — Повнота корпусу й наскрізне приймання

**Стан:** 🔵 заплановано. **Залежності:** KR49.1–49.6 та KR49.8–49.10,
включно з усім перекладом KR49.3. Це фінальний KR, виконується після конструктора.

## Звіт приймання

Зафіксувати manifest revision, counts included/excluded/review, source revisions,
кількість повністю перекладених/reviewed/published/stale статей і реальний coverage
прив’язок до підкласів. Початкові 471 URL не є release target без дедуплікації.
Неперекладені матеріали не виключати лише для отримання зеленого відсотка.
Окремо — build ledger, reviewed recipes, executable levels, source-backed recommendation
groups та конкретні причини incomplete. Наявність tree UI без реального створення
персонажа не закриває O49.

## Матриця

| Випадок | Що довести |
|---|---|
| Класовий guide обох редакцій | Повний текст, items/multiclass sections, зміст, посилання |
| Dedicated subclass | Article → модалка → article section → назад → звичайний вибір |
| Comparison-only subclass | Точний розділ, assessment саме підкласу |
| Conditional / no overall rating | Умови збережені, загальне число не вигадане |
| Legacy підклас у 2024 | Редакція аналізу явна; автоматичного переносу ratings немає |
| Раса/підраса, feat, spell, magic item, multiclass | Повна аналітика є в каталозі й пошуку |
| Third-party / missing entity | Стаття читається; джерело явне; відсутній match не прихований |
| Source update / redirect / network failure | Stable links, stale state, відредагований переклад збережений |
| Example build зі статті / дерево з меню | Варіанти, пояснення, налаштування, source refs, повернення без втрати draft |
| Складання персонажа обох редакцій | Перевірка picks → summary/ім’я → DB/sheet, чинний creator draft збережений до застосування |
| Мультикласовий / вищого рівня recipe | Правильний порядок progression, class levels, ASI, заклинання й resources |
| Незавершений вибір / збій / повтор submit | Явний залишок, без фальшивого успіху, часткового персонажа чи дубля |

У браузері на телефоні й десктопі: direct URL, пошук, anchors, повний аналіз в одній
модалці, Back, Escape, focus return, scroll return, draft preservation, таблиці.
Використовувати свій порт/dist/profile; сервер і login власника не чіпати.

## Технічні та редакторські гейти

- [ ] Усі included статті мають перевірений повний переклад; необлікованих пропусків немає.
- [ ] Extraction report чистий або кожна аномалія вручну звірена й виправлена.
- [ ] Редактор перевірив оцінки/контекст, числа, таблиці та аргументацію кожної статті.
- [ ] Немає unresolved первинних subclass bindings чи битих внутрішніх адрес.
- [ ] Вибір у конструкторі працює через чинний механізм; читання не змінює draft.
- [ ] Конструктор за recipe реально створює перевірених персонажів стартового
  й вищого рівня, включно з підтриманим мультикласовим пілотом; рекомендації не вигадані.
- [ ] Типи, lint і відповідні no-DB/content checks зелені; build без DB/network доступу.
- [ ] Production-code пройшов `clean-code-guard`; браузерна матриця має докази.
- [ ] На однакових production builds виміряно JS до/після: corpus не з’явився в root
  чи початкових кроках конструктора; search/full-reader довантажуються за дією.

Межі результату записати окремо: реалізовано / корпус перевірено / закомічено /
задеплоєно. Пуш не дозволений цим планувальним запитом. Якщо власник згодом доручить
пуш, виконати актуальні CI guards та перевірити delivery. Для локального приймання
не вимагати непогодженого деплою.
