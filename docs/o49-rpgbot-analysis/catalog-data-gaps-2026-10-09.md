# Прогалини каталогу 2014 за авторськими прикладами RPGbot (2026-10-09)

Для власника. Сід, схему й production агент не змінював. SQL лежить у
[catalog-data-gaps-2026-10-09-owner-applies.sql](catalog-data-gaps-2026-10-09-owner-applies.sql) і перевірений лише на локальній
`spells_test` (127.0.0.1:5433) у `BEGIN … ROLLBACK`; після відкоту стан бази збігся з початковим. Процедура: SQL → власник застосовує →
`bun run db:pull` → правка сідів у тому ж зрізі (інакше перезасів поверне старі дані) → перекомпіляція зачеплених специфікацій.

Джерела: пінована ревізія дзеркала 5etools `e5f3e77b303a92df10487207857200245e71957c` (`source-lock.json`). У локальній теці
`data/5etools/raw` є `races.json`, але немає `backgrounds.json` і `items-base.json`; їх знято з того самого коміту
(`data/backgrounds.json`, `data/items-base.json`) для цього документа, у репозиторій вони не додавалися.

## 1. Гіфф: Атлетика від раси (дані)

- **Каталог:** `race` `GIFF_SPELLJAMMER`, `skill_proficiencies = ["ATHLETICS"]`.
- **Джерело:** `races.json`, `Giff` (AAG, с. 12): `skillProficiencies: null`. Риси гіффа — Astral Spark, Firearms Mastery, Hippo Build; навичок немає.
- **Спотворює:** у `fighter-psi-warrior-2014` довелося замінити Атлетику Солдата на Виживання як «вибір платформи», бо лист вважає Атлетику расовою.
- **Виправлення:** SQL §1 (`UPDATE 1` у пробі). У сіді — `prisma/seed/raceSeed.ts`, блок `Races.GIFF_SPELLJAMMER` (~рядок 1250). Після `db:pull` і регенерації каталогу прибрати `skills.background: ["SURVIVAL"]` зі специфікації та перекомпілювати.

## 2. Шабля з двома лезами (дані)

- **Каталог:** у `weapon` лише `SCIMITAR` (2014 і 2024); значення enum `WeaponCategory` `DOUBLE_BLADED_SCIMITAR` немає.
- **Джерело:** `items-base.json`, `Double-Bladed Scimitar` (ERLW, с. 21): 2к4 рубальна, властивості «особлива» й «дворучна», військова.
- **Блокує:** `paladin-oath-of-the-watchers-2014` (автор радить цю зброю; там ще й зміна расової навички Гаренгона, тож специфікація лишається blocked).
- **Виправлення:** SQL §2а (`ALTER TYPE … ADD VALUE`, проба `ALTER TYPE` пройшла) окремою транзакцією, потім §2б (`INSERT`; у пробі перевірено типи й колонки через `INSERT … SELECT … WHERE false`, бо нове значення enum не використати в тій самій транзакції). Сід: `prisma/seed/weaponSeed.ts` (поруч із `WeaponCategory.SCIMITAR`, ~рядок 256). Властивість «особлива» потребує тексту правила на листі — перевірити відображення `SPECIAL`.

## 3. Переслідуваний: фіксовані навички замість вибору двох із чотирьох (дані + код)

- **Каталог:** `background` `HAUNTED_ONE` (джерело `COS`), `skill_proficiencies = ["ARCANA","INVESTIGATION"]`, мов на вибір 2, інструментів немає.
- **Джерело:** `backgrounds.json`, `Haunted One` (VRGR, с. 34): навички — вибір двох із Магії, Розслідування, Релігії, Виживання; мови — одна стандартна та одна з Abyssal, Celestial, Deep Speech, Draconic, Infernal, Primordial, Sylvan, Undercommon; інструментів немає. Варіант `RHW` (Магія, Виживання й ігровий набір) — інша книга.
- **Блокує:** `barbarian-path-of-wild-magic-2014`, `bard-spirits-2014`, `paladin-oath-of-devotion-2014`, `ranger-gloom-stalker-2014`, `rogue-arcane-trickster-2014`: автори беруть Релігію, Виживання або інший набір, якого з фіксованими Магією та Розслідуванням не отримати. Частина з них ще й міняє мову на інструмент.
- **Виправлення:** лише зміна даних шкодить: сервер і крок навичок передісторії читають тільки фіксований масив (`background.skillProficiencies` як список; форма `{options, choiceCount}` для передісторій не підтримана — `ready-preset-skill-sources.ts` бере `fixed`). Тому потрібні разом: (а) код вибору N навичок передісторії (поряд із `backgroundCustomization` і навичкою підкласу); (б) дані `skill_proficiencies = {"options":["ARCANA","INVESTIGATION","RELIGION","SURVIVAL"],"choiceCount":2}`. SQL для (б) не виділено у файл, щоб його не застосували раніше за код. Сід: `prisma/seed/backgroundSeed.ts`, `BackgroundCategory.HAUNTED_ONE` (~рядок 897); джерело `COS` у каталозі лишилося від старого видання — зіставити з VRGR.

## 4. Слідчий: версія зі Sword Coast (дані + код)

- **Каталог:** `INVESTIGATOR` (`SCAG`): Аналіз поведінки + Розслідування, 2 мови на вибір, інструментів немає.
- **Джерело:** `backgrounds.json`, `Investigator` (VRGR, с. 35): вибір двох із Аналізу поведінки, Розслідування, Уважності; набір для гриму й інструменти злодія; мов немає. Автори RPGbot беруть саме її.
- **Спотворює:** `artificer-alchemist-fairy-2014`, `artificer-artillerist-centaur-2014`, `artificer-battle-smith-autognome-2014`, `bard-creation-2014` (автор очікує Уважність, а каталог її не дає). Пресети беруть навички каталогу й позначають розбіжність у `incomplete`.
- **Виправлення:** окрема передісторія з новим значенням `BackgroundCategory` (наприклад `INVESTIGATOR_VRGR`; `ALTER TYPE … ADD VALUE`, ключ у `src/lib/refs/translation.ts` і словнику за правилами скіла перекладу), `skill_proficiencies = {"options":["INSIGHT","INVESTIGATION","PERCEPTION"],"choiceCount":2}`, `tool_proficiencies = {DISGUISE_KIT,THIEVES_TOOLS}`, `languages_to_choose_count = 0`; потрібен той самий код вибору навичок, що й у §3. Нову назву передісторії треба погодити за воротами нових термінів — SQL не готувався, доки термін не затверджено.

## 5. Напівельф зі спадком дроу: «Магія дроу» нічого не видає (код видачі)

- **Каталог:** варіанти Напівельфа (група «Універсальність напівельфа») є всі: Універсальність навичок, Ельфійське бойове навчання, Замовляння, Прудконогість, Маскування в дикій природі, Магія дроу, Швидкість плавання. Фіча `Drow Magic` повʼязана із Танцюючими вогниками, Вогнями фей і Темрявою (`_FeatureToSpell`), але персонаж їх не отримує.
- **Причина:** `data/2014/race-granted-spells.json` будує `scripts/5etools/build-race-granted-spells-2014.ts`; SCAG-варіанти напівельфа в ньому свідомо пропущено (`SOURCES_WITHOUT_OUR_RACES`), а видача шукає лише за расою й підрасою, не за расовим вибором. Характеризація: `tests/actions/half-elf-descent-cantrip-2014.test.ts`, `it.fails`.
- **Джерело:** `races.json`, підраса `Variant; Drow Descent` (SCAG): Танцюючі вогники з 1-го рівня, Вогні фей з 3-го, Темрява з 5-го (Харизма).
- **Блокує:** `ranger-beast-master-2014` (разом із зміною навички передісторії).
- **Виправлення:** без SQL: розширити генератор і `findEarnedRaceSpells2014` на «расовий вибір» як ключ, підʼєднати до місць, що викликають `saveRaceSpellGrants2014` (створення, підвищення рівня, ремонтний прогін). Окремий KR. Запис у [KNOWN-BUGS.md](../KNOWN-BUGS.md).
- Варіант «Замовляння» (спадок Місячного/Сонячного ельфа) цього зрізу підтримано: правило `RACE_SPELL_CHOICES_2014` для `HALF_ELF_2014`.

## 6. Дампір з Ааракокрою як базовою расою (дані + код)

- **Каталог:** `DHAMPIR_VRGTR`: швидкість 35, польоту немає, `skill_proficiencies = {"options":[],"chooseAny":true,"choiceCount":2}`.
- **Джерело:** `races.json`, `Dhampir` (VRGR, с. 16): «Ancestral Legacy» — якщо лінійність замінює расу, можна зберегти її навички та швидкості лазіння, польоту й плавання; якщо нічого не зберігати (або обрати лінійність при створенні), персонаж обирає дві навички. Ааракокра `AARAKOCRA_MPMM` у каталозі має політ 30.
- **Блокує:** `monk-way-of-the-long-death-2014` (автор: політ Ааракокри замість двох вільних навичок).
- **Виправлення:** варіант раси (`race_variant`: нове значення enum `Variants`, `overrides_flight_speed = 30`) плюс код, що в цьому варіанті не просить двох вільних навичок. SQL не готувався: без коду варіант дав би і політ, і дві навички.

## 7. Адепт метамагії: риса без опцій (дані + код)

- **Каталог:** `feat` `METAMAGIC_ADEPT` має 0 рядків у `feat_choice_option`; десять опцій групи «Метамагія» (`choice_option`) існують для Чародія (3, 10, 17-й рівні). Опису «2 очки чародійства» модель не має.
- **Джерело:** TCE (Metamagic Adept): дві метамагії зі списку Чародія та 2 очки чародійства.
- **Блокує:** `sorcerer-variant-human-storm-sorcery-tempest-2014` (автор бере Перетворене й Спарене заклинання). Специфікація залишається ready з `incomplete`.
- **Виправлення:** SQL §3 додає 10 звʼязків (у пробі `INSERT 0 10`) і НЕ застосовується, доки `findFeatChoicePickCount` (`src/rules/feat-choice-pick-count.ts`) не знає, що ця риса бере 2 опції групи метамагії (інакше конструктор дозволить 1). Очки чародійства від риси та показ на листі — окремо. Запис у [KNOWN-BUGS.md](../KNOWN-BUGS.md).

## 8. Експертиза в інструментах (модель)

- **Модель:** володіння інструментами — рядки тексту в `customProficiencies` листа, окремої сутності чи колонки немає; `PersSkill.proficiencyType = EXPERTISE` існує лише для навичок, `expertiseSchema` — масив навичок.
- **Джерело:** Пройдисвіт 2014, Expertise: дві навички або одна навичка й інструменти злодія (`class-rogue.json`).
- **Блокує:** `rogue-arcane-trickster-2014` (автор бере експертизу в інструментах злодія); також будь-який Пройдисвіт з таким вибором.
- **Оцінка:** мінімум — поле `toolExpertise` у чернетці, пункт у кроці експертизи, рядок «Експертиза: інструменти злодія» у `customProficiencies`, перевірка на сервері; бонус на листі автоматично не рахується. Це нова підсистема листа, тому не будувалась; потрібне рішення власника (раніше власник вирішив, що рідкісні вибори йдуть текстом на листі, але «розширювати, а не лишати текстом» — пізніше рішення).

## Не прогалина каталогу, але було у списку

- **Пункт 7 завдання, `subclassOptions: ["Insight"]` для Домену миру.** У Домені миру немає вибору підкласу в каталозі (`subclassChoiceOptions` порожні): «Знаряддя миру» — навичка у фічі підкласу (`skillProficiencies {options: INSIGHT/PERFORMANCE/PERSUASION, choiceCount: 1}`). Це не помилка перевірки `ready-preset-identity`; для такого вибору потрібне поле `skills.subclass` (додане агентом хвилі 2), і `d4-dispenser-cleric-peace-2014` уже його має.
- **«Кмітливий дослідник» і «Улюблений ворог».** Каталог правильний: обидві опції мають `skillExpertises`/`languagesToChooseCount`; пресет раніше їх не враховував (виправлено в коді).
