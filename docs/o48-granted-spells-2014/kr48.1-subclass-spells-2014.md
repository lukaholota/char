# KR48.1–48.2, 48.4 — заклинання підкласів 2014: дані, запис, ремонт

**Стан:** ✅ на проді 2026-09-27: коміт be4c6d2, сід, ремонт.

## Що зроблено

**Дані (KR48.1).** Джерело — поле `additionalSpells` підкласів у пінованому дзеркалі 5etools: воно
вже розкладає «рівень класу → заклинання» за механікою (`prepared`, `known`, `expanded`, `innate`).
Генератор [`scripts/5etools/build-subclass-granted-spells-2014.ts`](../../scripts/5etools/build-subclass-granted-spells-2014.ts)
бере лише `prepared` і `known` і пише [`data/2014/subclass-granted-spells.json`](../../data/2014/subclass-granted-spells.json):
**48 підкласів, 366 заклинань**. Зіставлення «клас|підклас|книга → наш enum» явне; новий підклас із
заклинаннями в наступній ревізії дзеркала зупиняє генерацію, а не губиться мовчки.

Поза файлом свідомо (поле `uncovered`) — усе, де заклинання обирає гравець:

| Підклас | Чому |
|---|---|
| Коло землі | заклинання залежать від обраної місцевості — вісім варіантів |
| Божественна душа | від обраної спорідненості — пʼять варіантів |
| Містичний лучник | одне з двох замовлянь на вибір |
| Колегія знань, домени природи, смерті, таємниць | «обери замовляння» (підготовлені заклинання доменів природи, смерті, таємниць — у файлі) |

Розширені списки покровителів (Безодня, Відьмацький клинок…) у файл не входять: за книгою 2014 вони
лише **додаються до списку, з якого гравець обирає**, і крок вибору їх уже пропонує
([KR31.18](../o31-builder-release-quality/)).

Сід [`prisma/seed/subclassGrantedSpells2014.ts`](../../prisma/seed/subclassGrantedSpells2014.ts) →
`bun run seed:subclass-granted-spells-2014:test|prod` (без `--apply` — показ). Зводить `subclass_spell`
з файлом лише для підкласів із файлу: додає, прибирає, виправляє рівень. На клоні: +365 (Магічна рука
Містичного спритника вже стояла з KR31.18), повторний прогін — 0. Місячне чародійство вивчає всю
таблицю — по заклинанню кожної фази на рівень: так каже текст риси «Lunar Embodiment» у нашому сіді,
фаза впливає лише на безкоштовне накладання.

**Запис (KR48.2).** Правило видачі вже було спільне для обох редакцій з KR31.5
(`findMissingSubclassSpells`), бракувало даних і двох місць:

- **конструктор** не видавав заклинань підкласу взагалі — у 2014 домен, покровитель і родовід
  обираються на 1-му рівні. Тепер `saveRuleGrantedClassSpells` у `character-creation.ts` кладе і
  класові, і підкласові;
- **рішення власника [Р53](../DECISIONS.md#р53)**: заклинання, яке гравець уже тримав своїм вибором,
  підклас перемічає як своє, а не пропускає. Одна функція `findSubclassSpellGrants` /
  `writeSubclassSpellGrants` у `src/server/db/always-prepared-spell-grants.ts` — для конструктора,
  майстра підвищення й ремонту.

Фільтр кроку вибору (`loadRuleGrantedSpellIds`) і лічильники відомих/підготовлених (`excludeFrom*`)
підхопили дані 2014 без змін: чародій Абераційного розуму не бачить Mind Sliver серед замовлянь на
вибір, а три псіонічні заклинання не зʼїдають його ліміту відомих.

**Ремонт (KR48.4).** [`scripts/repair-2014-granted-spells.ts`](../../scripts/repair-2014-granted-spells.ts)
→ `bun run repair:granted-spells-2014:test|prod` (з KR48.3 — ще й раса та біом) (без `--apply` — показ, `--verbose` — по персонажу).
Нічого не видаляє. Рахує тим самим `findSubclassSpellGrants`, що й майстер.

Оцінка на проді 2026-09-26 (лише читання, розрахунок із файлу — у проді `subclass_spell` 2014 ще
порожній, тож сам прогін там покаже нуль до сіду):

| | |
|---|---:|
| персонажів, яких торкнеться | **2 652** |
| нових рядків | **6 815** |
| перемічено (гравець тримав сам) | **1 956** (з них руками — 1 943) |

Найбільше: Домен життя 792, Абераційний розум 706, Домен світла 559, Домен могили 447, Артилерист 382.

   відкат — повернути поля перемічених рядків із копії й видалити додані.

   повторний показ — «0 із 2979». Разом 38 640 рядків `pers_spell` 2014.
