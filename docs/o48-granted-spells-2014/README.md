# O48 — Заклинання від підкласу й раси 2014 лягають у список самі

**Стан:** 🟡 0 / 5 — KR48.1, 48.2 і інструмент 48.4 готові в коді й на клоні 2026-09-26; прод чекає коміту, сіду й згоди на ремонт · **Відкрито** 2026-09-26 за словами власника: «в нас є заклинання за клас,
підклас, расу, підрасу… виписані, що видаються на певних рівнях, і в нас уже є форма для обирання
заклинань, а в список заклинань персонажа автоматично ці заклинання завжди підготованими не
додаються — це системна проблема» (скрін: «Заклинання патрона (Безодня)» на картці підкласу).

**Залежить від:** [KR31.5](../o31-builder-release-quality/kr31.5-spells-2024.md) (механізм для
2024), [O37](../o37-class-granted-spell-choices/) (третє джерело — опції підкласу),
[KR18.5](../o18-2024-character-parity/kr18.5-character-level-traits.md) / `scripts/repair-2024-species-level-grants.ts`
(ремонтний прогін «заслужено мінус є»).

## Коротко

Механізм уже є, і він працює — **лише для 2024**. У 2014 немає даних, на які він спирається:
таблиці «рівень класу → заклинання» підкласів 2014 у базі порожні, а рядки рас 2014 на листі не
пишуться взагалі. Тому гравець 2014 додає заклинання домену, клятви чи раси руками — або не
додає й не знає, що вони в нього є.

## Що каже книга (2014) — чотири різні механіки, не одна

«Виписані на рівнях» заклинання в 2014 поводяться по-різному, і ціль не має звести їх до
одного «завжди підготовлені»:

| Механіка | Хто | Що робить білдер |
|---|---|---|
| **Завжди підготовлені, поза лімітом** | домени клірика, клятви паладина, кола друїда (Земля за місцевістю, Спори, Дике полумʼя), підкласи артифіцера | рядок сам, `isPrepared`, `excludeFromPreparedCount` |
| **Відомі самі, поза лімітом відомих** | Aberrant Mind, Clockwork Soul, магія підкласів слідопита XGtE/TCoE (Gloom Stalker, Horizon Walker, Monster Slayer, Fey Wanderer, Swarmkeeper), бонусні замовляння (Light Domain, Celestial) | рядок сам, `excludeFromKnownCount` |
| **Розширений список — гравець обирає** | покровителі чаклуна (зокрема Безодня зі скріна), Divine Soul | заклинання **лише пропонуються** у кроці вибору, автоматично не додаються — вже так працює |
| **Вроджена магія раси** | Tiefling, Drow, Duergar, Firbolg, Fairy, Kobold, Yuan-ti, Hexblood… | рядок сам на рівні **персонажа** (1/3/5), своя характеристика, раз на довгий відпочинок |

Тобто сам скрін — випадок, де автоматичне додавання було б **помилкою**: «ці заклинання
додаються до списку заклинань чаклуна», а вивчає їх гравець своїм вибором. Для нього ціль лише
перевіряє, що крок вибору їх справді пропонує на кожному рівні.

## Backlog — вибір гравця, а не видача

Ціль закриває заклинання, які книга **називає поіменно**. Там, де гравець **обирає** заклинання,
потрібен крок вибору в майстрі, а не видача — це окрема робота:

- Високий ельф — замовляння чарівника (326 персонажів на проді), Кобольд — Драконяче чаклунство,
  Астральний ельф — одне з трьох замовлянь;
- замовляння доменів природи, смерті й таємниць, бонусне замовляння Кола землі;
- Колегія знань — Додаткові магічні таємниці (54);
- Божественна душа — спорідненість (39; опції в базі немає);
- Містичний лучник — одне з двох замовлянь (31).
