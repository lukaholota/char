2014 ↔ 2024. Гілка `night/rules`. У прод нічого не пишемо: сіди, SQL і перегенерацію каталогу
запускає власник за командами з журналів задач.

перевірено, дії власника з точними командами й терміни на затвердження. Останній раунд зводить
їх тут у порядок дій власника.

## Рішення планувальника

- Вправність робимо даними: `race.skillProficiencies = {options: [], chooseAny: true, choiceCount: 1}`,
  як у Warforged 2014. Крок «Навички» і сервер уже обробляють групу раси. Сід іде через
  `seed:species-choices-2024`, бо `seed:2024` тягне пастку з рисою ASI. У каталозі правимо лише
  поле наявного рядка, тож ID проду не змінюються.
- Навичку наявним людям не вгадуємо: SQL для власника з явним переліком «персонаж — навичка».
- Magic Initiate від передісторії: список фіксує передісторія (ACOLYTE — клірик, GUIDE_2024 — друїд,
  SAGE_2024 — чарівник; `data/2024/normalized/backgrounds.json`). Замок діє, лише коли рису дала сама
  передісторія. Риса походження людини чи інший власний вибір лишаються вільними.
- Інструменти від рис — не баг: рішення власника 2026-09-14 (`src/rules/feat-tool-choices.ts`).
- BUG-036 і заміни 2024 правлять один `levelup-step.ts`, тому вони в різних раундах.
