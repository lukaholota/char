# O47 — питання власнику

## 1. Автор змінив хоумбрю після того, як друїд його прикріпив

**Рекомендація:** форма показує актуальний статблок. Так уже поводяться хоумбрю-заклинання на листі,
і так велить [Р25](../DECISIONS.md#р25): персонаж посилається на контент ключем, а не копією.

## 2. Автор видалив хоумбрю

**Рекомендація:** рядок форми лишається, картка показує «форма недоступна», як для каталожної
істоти, що зникла з каталогу. Персонаж нічого не втрачає мовчки.

## 3. Чуже хоумбрю

**Рекомендація:** прикріплювати можна будь-яку хоумбрю-істоту з бестіарію, не лише свою, — як
хоумбрю-заклинання.

## 4. Придатність хоумбрю-істоти

**Рекомендація:** ті самі правила, що для каталогу (тип «звір», показник небезпеки, польоти й
плавання за рівнем). Непридатна прикріплюється з попередженням ([Р-3](../DECISIONS.md)), вхід у
неї заборонено — без винятків для хоумбрю.
