# KR8.3 — Очищення хедерів, Sans-serif типографіка, Mobile-First відступи, іконки та статблоки

**Ціль:** [O8](README.md) · **Статус:** ✅ зроблено (2026-08-16)

## Мета

Прибрати візуальний шум і дублювання в заголовках каталогів, замінити антикварний шрифт службових заголовків на чистий геометричний Sans-serif, налаштувати безпечні відступи для мобільних пристроїв (67% трафіку), додати іконки категорій та адаптувати вигляд статблоків бестіарію.

## Узгоджений scope

1. **Очищення хедерів каталогів:**
   - Прибрати з хедерів сторінок рис та бестіарію дублюючу назву-плашку «2024», лічильники «75 з 75» та довгий описовий текст.
   - Залишити лаконічний, компактний заголовок та рядок швидкого пошуку/фільтрів.

2. **Оновлення шрифтів (Шрифт «Замовляння» та рівнів):**
   - Замінити романський шрифт `Forum` у заголовках груп та лічильниках на чистий Sans-serif (`Inter` з кириличним сабсетом або `Outfit` / `Geist`).
   - Забезпечити чіткий кернінг, легку читабельність на мобільних екранах та помірний `tracking-wide`.

3. **Mobile-First відступи та Safe Area:**
   - Додати обов'язковий клас `pb-28 md:pb-8` та підтримку `env(safe-area-inset-bottom)` до всіх сторінок каталогів і головної сторінки, щоб мобільний бар навігації не перекривав нижній контент та кнопки.

4. **Іконки за типами та категоріями:**
   - **Магічні предмети:** `Shield` (Обладунок), `Sword` (Зброя), `FlaskConical` (Зілля), `Scroll` (Сувій), `CircleDot` (Кільце/Перстень), `Wand2` (Жезл/Паличка), `Sparkles` (Дивовижний предмет).
   - **Риси:** `Sparkles` (Походження), `Award` (Загальна), `Crown` (Епічний дар), `Swords` (Бойовий стиль).
   - **Бестіарій:** `PawPrint` (Звір), `Skull` (Нежить), `Sun` (Небожитель), `Flame` (Дракон), `Sparkles` (Фея), `Eye` (Аберація), `Bot`/`Cog` (Конструкт), `Wind` (Елементаль).

5. **Адаптивні статблоки бестіарію:**
   - Оновити `CreatureStatblockCard`: компактна 2-колонкова адаптивна сітка атрибутів і модифікаторів, опірності та дії у вільному потоці без обрізання тексту чи жорстких фіксованих висот.
