# KR8.1 — Єдиний компонент `ContentListPage` та виправлення модалок на десктопі

**Ціль:** [O8](README.md) · **Статус:** ✅ зроблено (2026-08-16)

## Мета

Створити уніфікований, конфігурований компонент `ContentListPage<T>` для всіх спискових сторінок платформи (заклинання, магічні предмети, риси, бестіарій та майбутні каталоги) та усунути конфлікт подвійного відкриття модального вікна на комп'ютері.

## Узгоджений scope

1. **Компонент `ContentListPage<T>`:**
   - Респонсивний макет: Split-screen з фіксованою правою панеллю деталей на десктопі ($\ge 1024\text{px}$) та плавний повноекранний Drawer/Modal на мобільних пристроях ($< 1024\text{px}$).
   - Вбудована віртуалізація списків через `Virtuoso`, підтримка групування за рівнями/категоріями/типами.
   - Пошуковий рядок з дебаунсом та кнопка швидких фільтрів з підрахунком активних фільтрів.
   - Підтримка тем: бурштинова (`amber-400`/`amber-500`) для 2024 та бірюзова (`teal-400`/`teal-500`) для 2014.

2. **Виправлення десктопного багу модалок:**
   - На екранах $\ge 1024\text{px}$ клік на елемент списку оновлює виключно активний елемент та `URLSearchParams` (`?spell=...`, `?item=...`, `?feat=...`).
   - Подія `spell:open` та виклик модальних вікон блокуються на десктопі, усуваючи дублювання деталей у сайдбарі та модалці.

3. **Міграція каталогів:**
   - Перевести `/spells` та `/2024/spells` на єдиний підхід.
   - Перевести `/magic-items` та `/2024/magic-items`.
   - Перевести `/feats` та `/2024/feats`.
   - Перевести `/bestiary` та `/2024/bestiary`.
