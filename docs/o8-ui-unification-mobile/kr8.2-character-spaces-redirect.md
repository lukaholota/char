# KR8.2 — Сегрегація персонажів 2014/2024 та розумний редирект

**Ціль:** [O8](README.md) · **Статус:** ✅ зроблено (2026-08-16)

## Мета

Забезпечити сувору сегрегацію списків персонажів між просторами 2014 та 2024 років, налаштувати автоматичний перехід на конструктор створення персонажа, якщо у гравця ще немає персонажів відповідної редакції, та скоригувати навігацію.

## Узгоджений scope

1. **Розумний редирект на головній та в меню «Персонажі»:**
   - Для 2014 (`/char/home`): якщо у користувача 0 персонажів 2014 (`ruleset !== RULES_2024` / `ruleset === RULES_2014`) $\rightarrow$ редирект на `/char/create`. Якщо $\ge 1$ персонажів $\rightarrow$ відображати список персонажів 2014.
   - Для 2024 (`/2024/char/home`): якщо у користувача 0 персонажів 2024 (`ruleset === RULES_2024`) $\rightarrow$ редирект на `/2024/char`. Якщо $\ge 1$ персонажів $\rightarrow$ відображати список персонажів 2024.

2. **Сегрегація списків у `CharHomeClient` / `getUserPersHomeData`:**
   - На `/char/home` відображати виключно персонажів 2014 року.
   - На `/2024/char/home` відображати виключно персонажів 2024 року.
   - Кнопка створення нового персонажа у шапці списку створює персонажа правильної редакції (`/char/create` або `/2024/char`).

3. **Корекція навігаційного бару (`Navigation.tsx` та `Home2024Client.tsx`):**
   - Посилання «Персонажі» динамічно веде на `/2024/char/home`, коли користувач перебуває у просторі 2024 (`/2024/*`), та на `/char/home`, коли у просторі 2014.
   - Картка «ПЕРСОНАЖІ 2024» на головній сторінці 2024 веде на `/2024/char/home`.
   - Максимальний реюз існуючих компонентів без дублювання екранів.

## Готово, коли

- [x] Користувач без персонажів 2014 при переході на «Персонажі» автоматично потрапляє на `/char/create`.
- [x] Користувач без персонажів 2024 при переході на 2024 «Персонажі» автоматично потрапляє на `/2024/char`.
- [x] На сторінці `/char/home` відсутні 2024 персонажі, а на `/2024/char/home` — 2014 персонажі.
- [x] `Navigation.tsx` коректно перемикає URL посилання персонажів відповідно до редакції.
- [x] Unit та route тести проходять успішно.
