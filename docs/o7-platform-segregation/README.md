# O7 — Сегрегація платформ (2014 vs 2024) та 2024-каталоги

**Мета:** Розділити простори D&D 5e 2014 та 2024 на рівні маршрутів і навігації, завершити переклад і засівання описів рис 2024-видів, та надати повноцінний доступ до каталогів 2024-контенту (заклинання, магічні предмети, риси, бестіарій).

## Чому цей Objective виділено окремо

Після завершення O5 (фундамент правил) та O6 (імпорт нормалізованого 2024-контенту, створення персонажа з 2024-правилами):
- 2024-види (Species) мають короткі описи в картках, але описи конкретних рис (Species Traits) не були засіяні у таблицю `feature` / `race_trait`.
- Платформа потребує ясної сегрегації маршрутів (наприклад, `/2024/char`, `/2024/spells`, `/2024/magic-items`, `/2024/bestiary` поруч із дефолтними 2014-маршрутами `/char`, `/spells`, `/magic-items`, `/bestiary`), щоб зберегти 2014 як непорушний дефолт і водночас дати зручну навігацію у 2024-просторі.
- 391 заклинання 2024, магічні предмети, риси та бестіарій мають відображатися у відповідних 2024-каталогах з пошуком і фільтрами.

- D&D 5e 2014 — дефолтна редакція; жоден 2014-маршрут, сід чи тест не повинен зламатися.
- Переклад термінів — строго за `dictionary.json`.
- Жодних прямих змін до production без дозволу власника.
