# KR40.2 — Завантажувач і спрайт

**Ціль:** [O40](README.md) · **Залежить від:** [KR40.1](kr40.1-name-registry.md), [KR40.3](kr40.3-generated-glyphs.md) · **Статус:** ✅ закрито 2026-09-20

## Задача

За реєстром KR40.1 стягнути іконки з bg3.wiki, зібрати їх в один спрайт у `public/assets/`,
згенерувати мапу координат і поставити атрибуцію.

## Завантажувач

`scripts/fetch-bg3-spell-icons.ts` — `bunx tsx`, не в `prebuild`.

- Імена бере **лише** з `data/spell-icons/bg3-map.json`; нічого не вгадує.
- URL знімає через MediaWiki API (`action=query&prop=imageinfo&iiprop=url`) партіями по 50 —
  шлях до файлу на вікі містить хеш (`/w/images/2/29/Fireball_Unfaded_Icon.webp`), склеїти його
  самому не можна.
- `User-Agent` із назвою проєкту; послідовно, не паралельно — це чужий сервер.
- Кладе у `data/spell-icons/raw/<engName>.webp`, **у git** (215 файлів × 2,4 КБ ≈ 526 КБ). Так
  спрайт перезбирається без мережі, і вікі не опитується на кожній збірці.
- Прогін ідемпотентний: наявний файл того самого розміру не перезавантажує.

## Спрайт

`scripts/build-spell-icon-sprite.ts`:

- сітка 64 × 64, порядок — абетка `engName`, щоб diff був читабельний;
- `public/assets/spell-icons/sprite-<hash вмісту>.webp`, **webp q90** — заміряно на 48 справжніх
  іконках: q90 дає ~385 КБ на 215, lossless — 1,4 МБ, окремими файлами — 526 КБ;
- `src/lib/generated/spell-icon-sprite.json` — `{ file, cols, size, index: { engName: n } }`;
- імʼя з хешем робить файл незмінним, і `buildStaticAssetHeaders` для `/assets/` віддає його
  з довгим кешем; `public/sw.js` кладе `/assets/` у `SHELL_CACHE` cache-first — офлайн працює
  без окремої правки сервісворкера.

`data/spell-icons/raw/` у git, спрайт у git теж (він артефакт збірки, але без нього збірка йде в
мережу). Регенерація на тому самому `raw/` має давати той самий хеш.

## Атрибуція

Вимога [Larian Fan Content Policy](https://larian.com/fan-content-policy) — явне «неофіційне, не
на замовлення Larian». Ставимо один раз, у підвалі каталогу заклинань і на сторінці «Про проєкт»:

> Іконки заклинань — з [bg3.wiki](https://bg3.wiki), © Larian Studios. Неофіційний фанатський
> проєкт; не створений і не спонсорований Larian Studios.

Текст — у `src/lib/refs/`, не рядком у компоненті: місць два.

## Гейти

| Тест | Що тримає |
|---|---|
| `tests/content/spell-icon-sprite.test.ts` | кожен `engName` із мапи має індекс у спрайті; індексів рівно стільки, скільки записів; `cols × size` збігається з розмірами файлу |
| той самий | файл спрайта існує за іменем із `spell-icon-sprite.json` (захист від забутої регенерації) |

Зламати перед здачею: підмінити `cols` у згенерованому json — тест має почервоніти.

## Що вийшло

| | |
|---|---|
| Завантажено з вікі | **220 із 220**, `data/spell-icons/raw/`, 880 КБ; повторний прогін завантажує 0 |
| Спрайт | `public/assets/spell-icons/sprite-<хеш>.webp`, 1536 × 1472, 24 колонки, **798 КБ** |
| У спрайті | **538 іконок** — 220 з вікі, 318 зібраних ([KR40.3](kr40.3-generated-glyphs.md)). Каталог покрито повністю |
| Індекс | `src/lib/generated/spell-icon-sprite.json` — `file`, `size`, `columns`, `rows`, `index`, `source` |

`source` на кожну іконку — вимога [Р46](../DECISIONS.md#р46): шар має зніматися окремо, тож у
спрайті видно, звідки взялася кожна плитка.

**Якість 85, не 90.** Виміряно на нестиснутому зведенні: q75 — 644 КБ і відхилення 5,37; q85 —
837 КБ і 4,10; q90 — 1001 КБ і 3,16; q95 — 1190 КБ і 2,71. Приріст якості після 85 коштує
160 КБ і на 64 px не видно.

**Одна іконка вікі — 63 × 63** (`Staggering Smite`), решта 64 × 64; збирач тягне все до 64.
Звірка плиток зі спрайта з джерелами дає відхилення 8 і менше скрізь, крім неї — там 31, і це
**не дефект**: зсув на піксель від 63 → 64 дає велике RMSE на контрастній лінії, візуально
зображення однакові. Не «лагодити».

## Атрибуція

Текст — `src/lib/refs/icon-attribution.ts`, єдине визначення. **У розмітку його ставить
[KR40.4](kr40.4-render-everywhere.md)**, а не цей KR: сторінки «Про проєкт» у проєкті немає, а
підвалу в каталозі заклинань теж, тож місце треба створювати там, де KR40.4 і так відкриває
каталог. Зобовʼязання від цього не порушується — іконки нікому не показуються, доки KR40.4 їх не
намалює.

## Гейт

`tests/content/spell-icon-sprite.test.ts` — пʼять перевірок; зламано чотирма способами
(випала іконка, збрехало джерело, підмінено імʼя файлу, вирізано дисклеймер), кожного разу
червоніла саме та, що мала.

## Команди

```
bunx tsx scripts/fetch-bg3-spell-icons.ts      # тягне з вікі, ідемпотентно
bunx tsx scripts/build-spell-icon-sprite.ts    # збирає спрайт + індекс
```
