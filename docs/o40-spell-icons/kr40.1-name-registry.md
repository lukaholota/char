# KR40.1 — Реєстр відповідності назв

**Ціль:** [O40](README.md) · **Статус:** ✅ закрито 2026-09-20

## Задача

Скласти `data/spell-icons/bg3-map.json` — відповідність `engName` заклинання до імені файлу на
bg3.wiki. Реєстр, а не алгоритм: збіг назв нерівний, і кожну пару має переглянути людина.

## Чому не автоматом

Розвідка 2026-09-20 дала 215 із 525 по `engName` з аліасами, але сирий збіг бреше в обидва боки:

| Клас розбіжності | Приклад |
|---|---|
| Британське написання | `Colour Spray` ↔ Color Spray, `Armour of Agathys` ↔ Armor of Agathys |
| Суфікс `spell` для розрізнення зі сторінкою предмета | `Bane spell` ↔ Bane |
| Варіанти одного заклинання | `Chromatic Orb Fire`, `Command Halt`, `Bestow Curse Dread`, `Conjure Elemental Air Myrmidon` — брати базову або обрати одну представницьку |
| Своя назва в BG3 | `Bone Chill` — це Chill Touch; `Aegis of the Absolute`, `Arachnid Compulsion`, `Bursting Sinew` — заклинання BG3, яких у книгах немає |
| Складений запис книги | `Blindness/Deafness` проти файлу `Blindness`; `Bear's Endurance` / `Bull's Strength` / `Cat's Grace` — частини Enhance Ability |
| Немає взагалі | `Antimagic Field`, `Astral Projection`, `Awaken`, `Alarm`, `Banishing Smite` — усі 310 |

## Що має бути

1. **`data/spell-icons/bg3-map.json`** — обʼєкт `engName → wikiFile` (імʼя без `File:` і без
   `Unfaded Icon.webp`). Ключ спільний для обох редакцій: 538 унікальних `engName` на 2014 і 2024.
2. **`data/spell-icons/no-bg3-icon.json`** — явний перелік `engName`, для яких іконки немає, з
   короткою причиною (`не в BG3`, `частина Enhance Ability`). Явний список, а не мовчазна
   відсутність: інакше наступна сесія щоразу перевірятиме ті самі 310 назв.
3. Для варіантів — **одна представниця**, вибрана й записана (`Chromatic Orb` → `Chromatic Orb Fire`),
   а не перша за абеткою.

## Що зроблено

`data/spell-icons/bg3-map.json` — **220 пар**, `data/spell-icons/no-bg3-icon.json` — **318 назв**;
разом 538, рівно раз кожна. Покриття вийшло трохи вище за контрольне число розвідки
(215 / 210), бо частину дали ручні пари:

| Каталог | Із іконкою |
|---|---|
| 2014 | **220 із 525** (було 215 сирим збігом) |
| 2024 | **216 із 391** (було 210) |

203 пари дав нормалізований збіг (регістр, пунктуація, `colour → color`, `armour → armor`,
`favour → favor`, хвіст ` spell`). Решту 17 розведено руками.

### Перейменовані в BG3 — звірено на сторінці вікі

| Заклинання книги | Файл | Підстава |
|---|---|---|
| Chill Touch | `Bone Chill` | сторінка каже: «renamed from **Chill Touch**, the tabletop version's name» |
| Jump | `Enhance Leap` | сторінка посилається на Jump у Forgotten Realms Wiki |
| Fly | `Grant Flight` | «renamed from **Fly** … to distinguish it from the Fly action» |
| Divine Favor | `Divine Favour` | британське написання |
| Resistance | `Resistance Cantrip` | суфікс для розрізнення зі сторінкою стану |
| Blindness/Deafness | `Blindness` | у BG3 лише половина складеного запису |
| Conjure Woodland Beings | `Conjure Woodland Being` | однина в BG3 |

### Родини варіантів — обрана представниця

Вибір робився оком по контактному аркушу всіх варіантів, не за абеткою.

| Заклинання | Узято | Чому саме цей |
|---|---|---|
| Command | `Command Halt` | розкрита долоня — єдиний із пʼяти жестів, що читається як «наказ», а не як конкретний ефект (Approach, Drop, Flee, Grovel) |
| Find Familiar | `Find Familiar Raven` | Boo і Scratch — компаньйони сюжету, не фамільяри гравця; крук упізнаваний на 28 px |
| Spiritual Weapon | `Spiritual Weapon Greatsword` | простий клинок; решта — сокира, галябарда, келеп, спис, тризуб |
| Eyebite | `Eyebite Sickened` | чисте око без вкладеної фігури |
| Contagion | `Contagion Filth Fever` | в усіх шести однакове кільце, різниця лише в гліфі всередині; тут він найменш конкретний |
| Banishing Smite | `Banishing Smite Melee` | зброя, а не стріла |
| Branding Smite | `Branding Smite Melee` | те саме |
| Ensnaring Strike | `Ensnaring Strike Melee` | те саме |
| Create or Destroy Water | `Create Water` | крапля; у `Destroy Water` вона перекреслена |
| Conjure Minor Elementals | `Conjure Minor Elemental Azer` | вогняна фігура читається як елементаль; решта — мефіти льоду й багна |

### Спокусливі пари, які відхилено

Записано, щоб наступна сесія не перевідкривала питання: назва схожа, суть інша.

| Заклинання | Схожий файл | Чому ні |
|---|---|---|
| Dawn | `Break of Dawn` | дія пастки Dawnbreaker у Rosymorn Monastery, прапорець `[IsTrap]` |
| Etherealness | `Leave Ethereal Plane` | під-дія Blink, доступна лише в стані «Blinked to the Ethereal Plane» |
| Teleport | `Teleport to Submersible` | здібність NPC Omeluum, «cannot be learned by party members» |
| Synaptic Static | `Synaptic Discharge` | інша здібність BG3 |
| Summon Undead | `Turn Undead` | класова риса, не заклинання |
| Aura of Vitality | `Warden of Vitality` | здібність предмета BG3 |
| Compulsion | `Karsusʼ Compulsion` | сюжетна здібність BG3 |

Причина в `no-bg3-icon.json` для цих семи — розгорнута; для решти 311 вона одна: «немає в BG3».
Нечіткий прохід (`difflib`, поріг 0.72) по всіх незакритих назвах проти всіх невжитих файлів інших
пар не знайшов.

### Що лишилося невжитим і чому це нормально

176 файлів категорії не вжито: це або варіанти заклинання, базова іконка якого вже в реєстрі
(`Chromatic Orb Fire`, `Hex Strength`, `Disguise Self Masc Drow`, `Activate Call Lightning`,
`Reapply Hunterʼs Mark`), або заклинання й дії, яких у книгах немає (`Aegis of the Absolute`,
`Arachnid Compulsion`, `Hound of Ill Omen`, `Third Eye Darkvision`). Невжитий файл реєстру не
ламає — гейт вимагає повноти з боку заклинань, не з боку вікі.

## Гейт

`tests/content/spell-icon-map.test.ts` — без бази, читає `src/lib/generated/spells.json` і
`data/2024/normalized/spells.json`:

- кожен ключ мапи є серед 538 `engName` (захист від одруку в ключі);
- мапа й `no-bg3-icon.json` разом покривають усі 538 рівно раз — ані діри, ані перетину;
- жоден файл вікі не вжито двічі (спільна іконка на два заклинання — помилка звірки).

Зламано перед здачею чотири рази, кожен раз червоний і відкочено: прибраний запис (покриття),
один файл на два заклинання (дублі), одрук у ключі (ключ + покриття), повне імʼя файлу замість
бази (формат). Прогін іде і в `bun run test`, і в `bun run test:no-db` — бази не торкається.

## Як перевіряти вручну

Перелік імен файлів знімається одним запитом:

```
curl -s "https://bg3.wiki/w/api.php?action=query&list=categorymembers&cmtitle=Category:Spell_icons&cmlimit=500&cmtype=file&format=json"
```

Сумнівну пару дивитися очима на `https://bg3.wiki/wiki/File:<Імʼя>_Unfaded_Icon.webp` — сторінка
файлу показує саму картинку й підписує, з якого заклинання вона взята.
