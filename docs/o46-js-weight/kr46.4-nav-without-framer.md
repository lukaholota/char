# KR46.4 — Меню навігації без framer-motion

**Стан:** 🔵 заплановано

## Що не так

`NavExtraMenu` живе в навігації кожної сторінки й імпортує `AnimatePresence`/`motion` з
`framer-motion` заради появи й зникнення меню. Через це ~127 КБ (`motion-dom` + `framer-motion`)
потрапляють у спільний JS усіх сторінок. Framer також потрібен головній, `/rules`, `/char/home`,
`MagicSlide` і `collapsible`, але там він і так вантажиться на своїх сторінках; конструктор,
каталоги й лист без меню його не потребують.

## Як зробити

1. Замінити анімацію меню на CSS (`data-state` + transition) або прибрати її зовсім — рух у UI
   за замовчуванням вимкнений (рішення власника 2026-09-20), тож варіант «без анімації» —
   перший кандидат; узгодити з власником перед правкою.
2. Перевірити, що `framer-motion` зник із чанків `/char/create` і каталогів.

## Критерій приймання

- Меню відкривається й закривається як раніше (клік поза меню, Escape, фокус), перевірено в
  Chromium з емуляцією телефона.
- `framer-motion` немає в спільних чанках (`/rules` ∩ `/char/create`).
- Замір «до» / «після» за [методикою O46](README.md#як-міряти).
