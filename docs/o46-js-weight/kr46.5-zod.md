# KR46.5 — zod у браузері

**Стан:** 🔵 чекає рішення власника ([questions.md](questions.md#1-zod))

## Що не так

zod 4 — 248 КБ розпакованого JS у конструкторі: найбільший окремий пакет після React. Він там,
бо `useStepForm` валідує кожен крок через `zodResolver(schema)`, а схеми лежать у
`src/lib/zod/schemas/persCreateSchema.ts` і поруч.

## Варіанти

| Варіант | Виграш | Ціна |
|---|---|---|
| А. `zod/mini` для клієнтських схем | значна частина з 248 КБ (tree-shaking по функціях) | інший API (`z.string().check(...)` замість ланцюжків), переписати схеми кроків; серверні лишаються на повному zod |
| Б. Кроки KR46.3 окремими чанками | zod усе одно в першому кроці через `useStepForm` — виграшу майже немає | — |
| В. Валідація кроків без zod на клієнті (ручні перевірки), zod — лише на сервері | майже всі 248 КБ | дві копії правил валідації — ризик розбіжності |
| Г. Лишити | 0 | 0 |

## Рекомендація

Спершу закрити KR46.2–KR46.4 і переміряти: якщо конструктор після них відкривається помітно
швидше за ~1,5 с на Pixel ×4, zod лишити (Г). Інакше — А, починаючи з одного кроку, і
переміряти перед рештою.
