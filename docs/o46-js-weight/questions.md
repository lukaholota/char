# O46 — питання власнику

## 1. zod

zod — 248 КБ у конструкторі. Варіанти й ціна — у [KR46.5](kr46.5-zod.md).

**Рекомендація:** не чіпати, доки не закриті KR46.2–KR46.4; тоді переміряти й вирішити за числом.

## 2. Анімація меню навігації

Щоб прибрати framer-motion зі спільного JS ([KR46.4](kr46.4-nav-without-framer.md)), меню або
анімується на CSS, або зʼявляється без руху.

**Рекомендація:** без руху — так узгоджено з рішенням 2026-09-20 «рух за замовчуванням вимкнений»,
і це найменший код.

## 3. Sentry (~170 КБ скрізь)

Можна вантажити SDK після `load`, але тоді помилки перших секунд сторінки не потраплять у Sentry.

**Рекомендація:** не чіпати — моніторинг потрібен саме на старті, а виграш менший за KR46.2–KR46.4.
