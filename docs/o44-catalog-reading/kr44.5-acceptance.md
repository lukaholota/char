# KR44.5 — Наскрізне приймання читання й пошукових переходів

**Ціль:** [O44](README.md) · **Статус:** ⏳ заплановано · **Залежить від:** KR44.2–KR44.4.

## Браузерна матриця

Перевірити Chromium із дотиком на 375 / 390 px, десктоп 1440 px і WebKit на мобільному
розмірі. Використати ізольований сервер / копію дерева за спільною памʼяттю; не чіпати
чужий `.next`. Каталоги статичні, база для цих сценаріїв не потрібна.

| Вхід | Кінцевий стан |
|---|---|
| Клас зі списку | Огляд; на телефоні один читальний Dialog |
| Картка підкласу | Тільки вибраний підклас, видимий батько й повернення |
| Пошук підкласу | Підклас відкритий без ручного переходу через клас |
| Пошук здібності класу | Правильний розділ і рівень, опис розгорнутий, ціль видима |
| Пошук здібності підкласу | Правильний підклас, опис розгорнутий, ціль видима |
| Пошук підраси / варіанта / їхньої риси | Правильна гілка й риса |
| Прямий URL, refresh, нова вкладка | Той самий кінцевий стан |
| Старий `jump` і числовий `class` / `race` | Сумісне відкриття нового представлення |
| Повторний результат після закриття | Читач знову відкривається на цілі |
| Конфліктний `q` / фільтр | Ціль посилання доступна, не підміняється першим результатом |
| Одна назва в різних власників | Відкрито того, кого назвав результат |
| Невідома гілка / здібність | Зрозумілий стан і шлях до батька |

## Історія й фокус

- [ ] «До класу» / «До раси» відновлює розділ, скрол і фокус джерела відкриття;
- [ ] browser Back проходить логічні рівні без порожніх записів і повторного відкриття після ×;
- [ ] Forward відтворює кінцеву ціль; прямий захід закривається без виходу з сайту;
- [ ] лише один власник browser-history: URL-керована модалка вимикає Dialog back-hook;
- [ ] збережено `history.state` Next, після `history.go` дотримано `waitForPendingHistoryBack`;
- [ ] посилання на заклинання / правило з опису відкривається й коректно повертає читача;
- [ ] Tab не виходить із модалки, Escape закриває її, фокус після закриття логічний;
- [ ] ціль не перекрита шапкою, скролиться видимий контейнер, а не прихована десктопна копія;
- [ ] немає нового автоматичного руху, фільтрів зерна чи повноекранного blur-шару;
- [ ] телефони не мають горизонтального переповнення чи подвійного скролу.
- [ ] у розгорнутих здібностях Варвара 2024 один заголовок «1 рівень» на групу,
      назви здібностей виразні, підпункти Люті відділені підзаголовками й відступами;
- [ ] те саме розділення працює в здібностях підкласу й рисах раси, зокрема коли читач
      розгорнув усі описи; короткі риси не потребують штучно доданих підпунктів.

## Гейти й доказ

Релевантні компонентні й content-тести, `tsc`, lint, `check:ui-decomposition`,
`check:db-boundary`; зміни пошуку перевірити проти наявних O36 / Р52 тестів. Критичні перевірки
мають падати при навмисному порушенні; зберігати файли перед мутацією, повертати із власної
копії, без git checkout / restore. Повний набір не запускати паралельно з lint.

У журнал внести URL прикладів, скриншоти й фактичні результати матриці. Не позначати новий
вигляд доступним на сайті до запитаного власником пуша й перевіреного деплою.
- **2026-09-26** — частково: Chromium 1440 і iPhone 13 на чужому dev :3000 — прямі адреси
  таблиці, підкласу зі здібністю, варіанта людини, здібності класу; переповнення сторінки
  немає, таблиця прокручується у своєму контейнері. Не пройдено: WebKit, «Назад»/«Вперед»
  у справжньому браузері, клавіатура, модалки заклинань з опису.
