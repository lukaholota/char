# KR44.2 — Адреса описує кінцеву ціль читання

**Ціль:** [O44](README.md) · **Статус:** ✅ 2026-09-26 · **Блокує:** KR44.3, KR44.4.

## Контракт

Один легкий модуль будує й розбирає ціль: редакція, каталог, батько, тип гілки, гілка,
здібність / риса. Він не імпортує повні каталоги. Пошук і читач використовують цей модуль.
Спершу знайти наявні URL-хелпери й повторно використати їх.

Рекомендований формат, остаточно зафіксувати під час реалізації:

```text
/classes?class=bard&view=subclasses&subclass=college-of-lore
/classes?class=bard&subclass=college-of-lore&feature=cutting-words-3
/classes?class=bard&view=features&feature=bardic-inspiration-1
/races?race=elf&branch=subrace:<key>&trait=<stable-key>
```

`/2024/` і `/no-ai/` зберігаються наявними маршрутними хелперами. `class` / `race` і далі
приймають старі числові ключі. Старий `jump=<subclass-slug>` відкриває підклас у новому
представленні; `jump=subrace:<key>` / `variant:<key>` відкриває гілку. `q` лишається пошуковим
запитом, а ціль можна відкрити незалежно від чинних фільтрів.

Рекомендований ключ здібності — англійська назва + рівень у межах конкретного власника.
Для расових рис — англійська назва в межах раси / гілки. Перевірити унікальність **після**
нормалізації слагів. Якщо є колізії, явно розвести стабільним ключем із наявних даних;
не додавати індекс масиву й не відкидати повтори. За потреби розглянути експорт наявного ID
генератором; нова колонка БД для цього не потрібна.

## Готово, коли

- [ ] будування й розбір адреси проходять round trip для кожного типу цілі;
- [ ] гейт обходить каталоги обох редакцій і підтверджує однозначне знаходження кожної цілі;
- [ ] підтримані старі `jump`, числові батьки, `q`, фільтри й `/no-ai/`;
- [ ] переклад назви або зміна порядку масиву не змінює ключ;
- [ ] невідома гілка / здібність показує зрозумілий стан із переходом до батька;
- [ ] немає нового імпорту JSON у глобальну оболонку чи легкі клієнтські хелпери.

## Журнал

- **2026-09-26** — план сформовано. У поточних даних повторів `(engName, level)` у межах
  власника немає; це не заміняє майбутній гейт на нормалізовані ключі.
- **2026-09-26** — `src/lib/catalogs/reading-target.ts`. Параметри: `class`/`race`, `view`,
  `subclass`, `subrace`/`variant`, `feature`. Риса раси теж `feature`, бо `trait` уже зайнятий
  фільтром ознак. Ключ здібності — слаг англійської назви без префікса власника й «(2024)» +
  рівень; гілки — слаг англійської назви (старий `jump=subrace:<KEY>` теж приймається).
  Гейт `tests/content/catalog-reading-targets.test.ts` обходить обидві редакції; бачений
  червоним на ключі без рівня, без старого `jump` і на навмисних колізіях.
