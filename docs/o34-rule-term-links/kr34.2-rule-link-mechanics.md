# KR34.2 — Посилання на правило: реєстр, розпізнавач, легкий чанк

**Ціль:** [O34](README.md) · **Статус:** ✅ закрито 2026-09-13 (клік по якорю в живому контенті — у KR34.4, де якорі зʼявляться) · **Залежить від:** [KR34.1](kr34.1-edition-honest-card.md)

## Мета

Сирий якір у тексті, так само як у заклинань
([KR25.1](../o25-spell-links/kr25.1-link-mechanics.md)), відкриває `TermInfoModal`, не забираючи
читача зі сторінки:

```html
<a href="/rules/conditions#paralyzed">паралізованим</a>
<a href="/2024/rules/actions#bonus-action">бонусною дією</a>
```

Прямий захід (нова вкладка, краулер, без JS) веде на справжню статичну сторінку довідника з якорем.
Редакція виводиться з `href`, не зі сторінки, — як у `spell-link.ts`.

## Що зробити

1. **Реєстр термінів-посилань** — один файл даних: ключ терміна, `engName`, для кожної редакції —
   адреса статті або стану. Обсяг — стани й дії з [README](README.md#чи-це-корисно), ≈ 27 на
   редакцію. Адреси перевіряються гейтом проти `rules-2014.json` / `rules-2024.json` і
   `getAllConditions` — якір, що не веде в існуючий підрозділ, червонить.
2. **Розпізнавач** — у [`term-link.ts`](../../src/lib/term-link.ts), поруч з `openTermLink`
   (свого другого не заводити). `FormattedDescription` пробує `findSpellLinkInHref`, потім
   розпізнавач правила, і відкриває модалку через `openTermLink`. `/no-ai/` тримається
   (`useNoAiHref`).
3. **Легкий чанк.** Модалці за посиланням не потрібні `rules-beyond-srd` (246 КБ gzip) і весь
   словник: досить статей і станів із реєстру. Зібрати генератором окремий JSON лише з потрібних
   підрозділів обох редакцій і вантажити його для посилань; важкий чанк лишається маркерам
   `{{}}`, у яких термін довільний. Виміряти gzip після збірки; оцінка — десятки КБ.

## Готово, коли

- [x] Клік по якорю стану й дії відкриває модалку на місці, адреса несе `?term=` — jsdom-тест;
      у Chromium — на першому звʼязаному контенті в KR34.4.
- [x] Редакція береться з `href`: якір 2014 на сторінці 2024 відкриває 2014 (тест).
- [x] Прямий захід на `href` дає статичну сторінку довідника з прокруткою до підрозділу
      (`/rules/conditions#condition-paralyzed`, Chromium).
- [x] `/no-ai/` зберігає префікс: якір іде через `useNoAiHref`, розпізнавач знімає `/no-ai`.
- [x] Гейт реєстру червоніє на вигаданому якорі й на якорі чужої редакції (показано зламом).
- [x] Розмір легкого чанка записано; перше відкриття терміна з реєстру тягне 120 КБ dev-JS проти

- [ ] Офлайн не перевірявся: сервісний воркер реєструється лише в прод-збірці, а збирати прод

- [x] Десктоп і емуляція телефона (маркер: перший тап — підказка, другий — модалка).

## Журнал

### 2026-09-13 — зроблено

**Реєстр** — [`src/lib/refs/rule-term-links.json`](../../src/lib/refs/rule-term-links.json), 44
терміни: 16 станів (Bloodied — лише 2024), 15 дій (Use an Object — 2014; Utilize, Magic,
Influence, Study — 2024), 13 правил (Opportunity Attack, Concentration, Advantage, Disadvantage,
Cover, Difficult Terrain, Surprise, Temporary Hit Points; Critical Hit, Resistance, Vulnerability,
Unarmed Strike — лише 2024). Кожна адреса — підрозділ, текст якого стане карткою: для 2024 обрано
короткі статті глосарію (`#cover-term--cover`), не довгі розділи. Два 2014-підрозділи не мають
`engTitle` у назві: атака нагоди лежить заголовком «Принагідні атаки» всередині «Ближніх атак»
(`#making-an-attack--melee-attacks`), концентрація — у `#concentration-rules`. Типи шкоди свідомо
не взято (див. README цілі).

**Механіка** — у [`term-link.ts`](../../src/lib/term-link.ts): `findTermLinkInHref`,
`findRuleTermHref`, `listRuleTermLinks`. Якір рендерить
[`RuleTermAnchor`](../../src/components/ui/RuleTermAnchor.tsx) — за зразком `SpellAnchor`, який
паралельна сесія того ж дня винесла з `FormattedDescription` (правка лягла поверх її версії).
Реєстр іде в клієнтський бандл рендерера: 44 рядки, одиниці КБ.

**Картка** за реєстром шукає підрозділ за адресою, а не за назвою: так 2014 «Advantage» дістає
«Перевагу й перешкоду», а «Concentration» — «Правила концентрації».

**Якорі станів.** Картки станів на сторінці довідника не мали `id` — прямий захід за
`#paralyzed` нікуди не прокручував. На сторінці 2024 уже стоїть стаття `#exhaustion`, тож
голий id станів дав би дубль; тепер `#condition-<id>` (`buildConditionAnchor`), тест KR30.3 на
`#blinded` оновлено свідомо. Chromium: `#condition-paralyzed` — елемент на 96 px від верху,
`[id="exhaustion"]` і `[id="condition-exhaustion"]` — по одному.

**Легкий чанк** — [`src/lib/generated/rule-term-cards.json`](../../src/lib/generated/rule-term-cards.json),
генерує `bun run generate:rule-term-cards` (файловий, без бази; включено в `generate:content`
перед `creator-content`). 44 × 2 картки: **131 КБ, 21 КБ gzip** проти ≈ 560 КБ повних джерел.
`findTermCard` бере його для термінів реєстру, решта маркерів — як і було. Опис джерел картки
винесено в [`term-sources.ts`](../../src/lib/term-sources.ts) — раніше він жив двома копіями
(чанк і тест), тепер третьою був би генератор. Гейт «чанк не відстав від довідника» показано
червоним зіпсованим файлом.

**Тести.** `tests/logic/rule-term-links.test.ts` (4: редакція в шляху, адреса веде в підрозділ і
картка показує саме його, без дублів, чанк актуальний), `tests/components/term-link.test.tsx` +3
(стан, дія 2024, чужий `/rules/` лишається переходом). Червоні до правки: 2 компонентні, 2 злами
реєстру, 1 злам чанка.

**Повний юніт-прогін:** 2 546 / 2 549. Три падіння чужі: `radiant-term-sweep` (2) — «променист-» у
`classes.json` і `creator-content-*.json`, перезібраних о 12:04–12:12 до початку цієї роботи;
`spell-mentions-linked` — таймаут під навантаженням (load 7,9), окремо 16 / 16.

**Браузер** (Chromium, :3000): `/bestiary/mummy-lord` маркер «Атака{{Attack}}» → «Довідник 2014 ·
Дії в бою · Атака», `?term=Attack`, Escape чистить адресу; iPhone 13 — перший тап підказка, другий
модалка. Помилок сторінки 0.
