# KR28.3 — Дикі форми в чарнику

**Ціль:** [O28](README.md) · **Статус:** ✅ · **Залежить від:** KR28.2

## Мета

Додати вибрані Дикі форми персонажа окремою секцією PDF, не дублюючи рендерер бестіарію.

## Що саме зробити

1. Розширити `PrintSection` секцією Диких форм і завантажувати форми через чинний безпечний
   доступ до `pers_wildshape`.
2. У модалці друку показувати пункт лише для друїда з непорожнім набором вибраних форм та
   вмикати його за замовчуванням. Зберегти можливість вимкнути його перед друком.
3. Друкувати кожну форму renderer-ом KR28.2: без картинки, marker-content і related-блоків.
4. Забезпечити однакову поведінку owned та share-token друку.
5. Додати регресійний тест, що дві або більше взяті персонажем риси та їхні вибрані опції й далі
   потрапляють у чинну секцію `FEATURES` один раз кожна.

## Готово, коли

- [x] Друїд із формами бачить default-on `Дикі форми`; без форм — не бачить порожнього пункту.
- [x] Вимкнення пункту справді прибирає всі сторінки форм.
- [x] Друкуються лише прикріплені персонажу форми, не весь доступний за правилами бестіарій.
- [x] Owned і share-token PDF містять той самий набір дозволених форм.
- [x] Форми використовують той самий компонент/renderer, що standalone-бестіарій.
- [x] Кілька рис і їхні опції не губляться в `FEATURES`.
