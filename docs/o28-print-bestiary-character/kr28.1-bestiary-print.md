# KR28.1 — Друк бестіарію

**Ціль:** [O28](README.md) · **Статус:** ✅ · **Залежить від:** нічого

## Мета

Дати Майстру вибрати одну або кілька істот у `/bestiary` та `/2024/bestiary` і відкрити один PDF
зі статблоками. Це перший пріоритет цілі.

## Що саме зробити

1. Додати в обидві редакції бестіарію режим вибору для друку за чинним патерном заклинань і
   магічних предметів; фільтрація й сортування не мають скидати вже вибране без явної дії.
2. Визначити стабільний print-key істоти разом із редакцією. Однаковий slug у 2014 і 2024 не
   повинен підмінити запис іншої редакції.
3. Додати API та серверне завантаження тільки з канонічних генерованих JSON бестіарію — не з
   семи застарілих рядків таблиці `creature` ([Р15](../DECISIONS.md#р15)).
4. Генерувати один PDF для непорожнього набору; відхиляти порожній, невалідний або змішаний з
   неіснуючими ключами запит зрозуміло й без часткового витоку даних.
5. Підключити мінімальний рендерер статблока без картинок; фінальна форма й print-проєкція —
   KR28.2.

## Готово, коли

- [x] В обох бестіаріях можна вибрати істот і надрукувати їх одним PDF.
- [x] Ключ однозначний за `ruleset`; колізія slug покрита тестом.
- [x] Завантажувач читає генерований каталог, а не Prisma `creature`.
- [x] Картинки не завантажуються й не вбудовуються в PDF.
- [x] API-помилки й непорожній happy path покриті тестами.
- [x] Чинний друк заклинань і магічних предметів не зрушив.
