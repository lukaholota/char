# KR17.2 — каталог 2024: звірка прози 250 записів

**Ціль:** [O17](README.md) · **Статус:** ⏳ не почато · **Залежить від:** [KR17.1](kr17.1-prose-check.md)

## Обсяг

250 записів, ранжованих `bun run rank:stale-2024` (див. [README](README.md) — розподіл за балом).
Партія — **25 записів згори за балом**, тобто ~10 сесій.

Перші 25 (бал ≥ 0.60) виміряні 2026-08-23 і починаються так:

```
0.91  Guidance          0.72  Cloud of Daggers    0.65  Rope Trick
0.79  Darkvision        0.72  Counterspell        0.65  Dominate Monster
0.77  Shapechange       0.71  Speak with Animals  0.65  Simulacrum
0.75  Detect Thoughts   0.70  Suggestion          0.63  Calm Emotions
0.72  Mass Suggestion   0.68  Mind Blank          0.63  Stinking Cloud
```

`Speak with Animals` відкладено до відповіді на питання 1 у [questions.md](questions.md).

## Що робить сесія

1. `bun run rank:stale-2024` — узяти наступні 25, яких немає в `ALIGNED_WITH_XPHB`.
2. Зняти оригінал XPHB із пінованого корпусу для кожного.
3. Переписати український текст **з оригіналу**, викликом скіла `dnd-ua-translation`.
4. Долити 25 імен у `ALIGNED_WITH_XPHB` і прогнати звірку прози з KR17.1.
5. Довести кожну нову перевірку червоною, відкотити побайтово.

## Чого сесія НЕ робить

- Не бере більше 25.
- Не вигадує терміну, якого немає в словнику, — відкладає запис поіменно.
- Не чіпає каталог 2014 (це KR17.4) і не пише в прод.

## Готово, коли

- [ ] Усі 250 записів звірено з оригіналом і внесено в храповик.
- [ ] Звірка прози KR17.1 по каталогу 2024 чиста або має поіменні винятки з причиною.
- [ ] Звірка полів лишилася на 1 (`Animate Objects`) або 0.
