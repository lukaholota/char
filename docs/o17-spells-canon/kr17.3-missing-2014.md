## Чому це сід, а не JSON

Каталог 2014 живе **в базі** ([Р2](../DECISIONS.md#р2), [Р17](../DECISIONS.md#р17)). Тому:

```
data/2014/new-spells/*.json → prisma/seed/newSpells2014.ts → seed:new-spells:test → прогін у прод
```

Перед сідом потрібні коди джерел у enum `Source`: `AI`, `SCC`, `LLK`, `AAG`, `SatO`,
`AitFR-AVT` — перевірити, яких бракує, і підготувати SQL у `db/changes/` для власника.
