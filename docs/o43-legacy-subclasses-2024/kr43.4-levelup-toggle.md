# KR43.4 — Перемикач «Підкласи зі старих книг» у майстрі підвищення

**Ціль:** [O43](README.md) · **Статус:** 🔵 заплановано · **Залежить від:** [KR43.2](kr43.2-seed.md), [KR43.3](kr43.3-generators-and-gates.md)

## Де саме

Крок підкласу 2024 існує **лише в майстрі підвищення**: конструктор створює персонажа 1-го рівня,
а `rules2024Strategy.needsSubclassSelection` відкриває підклас з 3-го
(`src/rules/strategies/rules2024.ts:17-19`; `MultiStepForm.tsx:479-483` передає рівень 1). Майстер
кладе крок, коли `selectedClass.subclassLevel === classLevelAfter` (`LevelUpWizard.tsx:620-625`,
`:895-900`) і рендерить спільний `SubclassForm` (`LevelUpWizard.tsx:1099-1105`). Це однаково для
основного класу і для мультикласу (гілка `selectedMulticlassRow`), тож одна правка в
`SubclassForm` покриває обидва.

`SubclassForm` також малює крок підкласу **конструктора 2014**. У контенті 2014 `legacySource`
завжди `null`, тому там перемикача немає і поведінка не змінюється — це треба пришпилити тестом.

## Поведінка

- Перемикач зʼявляється, лише коли в класу є хоч один підклас із `legacySource`.
- Підпис: **«Підкласи зі старих книг»**; під ним рядок: «Правила 2024 дозволяють підклас із
  книги 2014 без перевидання. Риси нижче 3-го рівня ви отримуєте на 3-му.»
- За замовчуванням вимкнений. Увімкнений одразу, якщо вже обраний підклас — легасі (повернення
  назад по кроках майстра).
- Увімкнений: легасі-картки йдуть **окремим блоком після** підкласів PHB 2024, кожна з
  `SourceBadge` (`src/lib/components/characterCreator/SourceBadge.tsx`) з кодом книги.
- Вимкнення при обраному легасі-підкласі скидає вибір (`subclassId` → порожньо,
  `subclassChoiceSelections` → `{}`), як уже робить клік по іншій картці (`SubclassForm.tsx:92-96`).
- Стан перемикача не зберігається ніде: це фільтр одного кроку, не налаштування персонажа.
- Мертве сортування за `source` (`SubclassForm.tsx:57-73` — поля в контенті немає, `sourcePriority`
  завжди 3) прибрати разом із закоментованим `SourceBadge` (`:109`): їх заміняє розбиття на блоки.

## Кроки

### 1. Логіка показу — окремим модулем

`check:ui-decomposition` зарізав деплой, коли логіка росла у великих компонентах (памʼять «CI-кроки
локально перед пушем»). Тому:

`src/lib/logic/legacy-subclass-visibility.ts`

```ts
export type SubclassCard = { subclassId: number; name: string; legacySource?: string | null };

export function hasLegacySubclasses(subclasses: readonly SubclassCard[]): boolean
export function isLegacyChosen(subclasses: readonly SubclassCard[], chosenId: number | null): boolean
export function splitSubclassesForStep<T extends SubclassCard>(
  subclasses: readonly T[], showLegacy: boolean, sortName: (subclass: T) => string,
): { current: T[]; legacy: T[] }        // legacy порожній, коли showLegacy = false
```

Юніт-тест `src/lib/logic/legacy-subclass-visibility.test.ts`: контент 2014 (усі `null`) → блок
легасі порожній і перемикача немає; 2024 з легасі → розбиття, сортування за українською назвою
(`localeCompare(…, "uk")`); обраний легасі → `isLegacyChosen` істина.

### 2. `SubclassForm.tsx`

- `const [showLegacy, setShowLegacy] = useState(() => isLegacyChosen(cls.subclasses, chosenSubclassId))`.
- `Switch` з `src/components/ui/switch.tsx` + `Label`; `onCheckedChange(false)` при обраному
  легасі — скидання вибору (див. «Поведінка»).
- Два блоки карток; заголовок другого — «Зі старих книг».
- `SubclassInfoModal` (`modals/SubclassInfoModal.tsx:60`) показує `subclass.source`; передати
  `legacySource ?? source` і рядок про зсув рівнів, коли `legacySource` є.
- Ніякого `swiper-no-swiping` / `stopPropagation` на `pointerdown` — майстер не в каруселі листа,
  але правило проєкту одне.
