- сід рис 2014 повторно на копії без зачистки KR43.2 → F отримує риси, привʼязані до рядка 2024.

## 2. Chromium

Рецепти — памʼять «Підроблена сесія для браузерного аудиту», «Браузерну перевірку блокує чужий next
dev», «Дотик фокусує перед кліком». Коротко: копія дерева, свій `distDir`, окрема база
`scripts/local-test-db.sh clone spells_browser_test` + сід KR43.2 туди, порт 3100, JWT через
`@auth/core/jwt` + `AUTH_SECRET`.

Сценарії, Playwright з `devices["iPhone 13"]` і десктоп:

1. Чорнокнижник 2024 2-го рівня → «Підвищити» → крок підкласу: легасі не видно; тап по перемикачу —
   зʼявився блок «Зі старих книг» з чотирма картками й бейджами; модалка «Джина» показує книгу й
   примітку про 3-й рівень.
2. Обрати «Джин» → рід Дао → крок заклинань: Sanctuary є, Thunderwave немає; примітка про список
   покровителя.
3. Назад на крок підкласу — перемикач увімкнений, «Джин» обраний; вимкнути — вибір скинуто.
4. Завершити → лист: шапка «Джин · Казан Таші з усім»; слайд рис має Судину джинна й список 2024;
   посилання зі списку відкриває заклинання **2024**.
5. `/2024/classes?class=warlock` — дві секції, «Підкласи (6)».
6. `Cmd+K` «Джин» на 2024-сторінці — лише 2014-результат.

Контрольний прогін на коді до O43: сценарій 1 має впасти на «перемикач існує» — інакше він нічого не
доводить.

## 4. Викатка на прод — порядок обовʼязковий

| Крок | Хто | Що | Перевірка |
|---|---|---|---|
| 1 | агент | пуш коду KR43.1–43.6 **без** прод-сіду | `gh run list` — деплой зелений; `git status -sb` = `origin/main`. Сайт працює як раніше: легасі-рядків у базі ще немає |
| 2 | агент | `bun run seed:legacy-subclasses-2024:prod` — показ плану | 4 створення, 0 оновлень рядків 2014 |
| 3 | агент | те саме з `--apply` | запит скриптом на `pg`: 4 рядки під `WARLOCK_2024`; повторний показ — порожній |
| 4 | агент | регенерація `creator-content-2024.json` і `classes.json` з робочої бази, коміт | diff: +4 підкласи з `legacySource`/`legacy`, решта байт-у-байт |
| 5 | агент | пуш коміту кроку 4 (це код, не лише доки — деплой запуститься) | `gh run list` зелений; якщо з якоїсь причини не запустився — `gh workflow run deploy.yml` |
| 6 | агент | живий сайт: крок підкласу чорнокнижника 2024 з перемикачем | скрін або прогін сценарію 1 на `char.holota.family` зі своїм персонажем |

Прод-сід агент ганяє сам: це upsert контенту, пройдений на клоні, без даних гравців (памʼять
«Безпечні сіди на прод агент ганяє сам»). DDL у цій цілі немає. Якщо крок 1 ще не на проді — крок 2
не починати: регенерація каталогів на кроці 4 впала б на `findSubclassSource`.

Після кроку 4 звузити два гейти KR43.3 з «легасі або жодного, або рівно реєстр» до «рівно реєстр»:
`subclass-spellcasting-2024.test.ts` і `catalog-prose-2014.test.ts` (`[0, N]` → `N`). До прод-сіду
закомічений контент легасі-рядків не має, тож суворіша форма червоніла б.
