# KR36.2 — Інфузії Винахідника в пошуку

**Ціль:** [O36](README.md) · **Статус:** 🟢 зроблено 2026-09-18 · **Залежить від:** [KR36.1](kr36.1-catalog-registry.md)

## Що робимо

Каталог інфузій ([KR9.2](../o9-catalogs-expansion/kr9.2-new-catalogs.md)) доїхав усюди, крім
пошуку. Додаємо його як категорію: підпис «Вливання Винахідника» (як у меню), редакції —
**лише 2014**, колектор із `getAllInfusions()`.

Колектор за зразком метамагії ([`omniSearchData.ts`](../../src/lib/omniSearchData.ts), 66 записів):

| Поле рядка | Значення |
|---|---|
| `title` | `nameUa` |
| `subtitle` | `engName` |
| `href` | `/infusions/<slug>` — сторінка запису вже є й збирається статично |
| `badge` | `minArtificerLevel` — «Рівень N» |
| `keywords` | `source`, `targetType` — **українською** (див. [KR36.5](kr36.5-human-keywords.md)) |
| `aliases` | `findAliasVariants(ruleset, ["infusion"], …)` |
| `visualKey` | `targetType` — те саме сире поле, яким малює іконку сама сторінка каталогу (правило Б9) |

Аліаси варті окремої уваги: гравці кажуть «інфузія», «вливання», «артефакти артифайсера» — треба
рядок у [`search-aliases.json`](../../src/lib/refs/search-aliases.json), інакше категорія
знайдеться лише точною назвою запису.

## Готово, коли

- [ ] `buildOmniSearchIndex("RULES_2014")` містить 66 інфузій, `("RULES_2024")` — нуль;
- [ ] інфузії є плиткою у вікні пошуку й табом фільтра в 2014 і **не зʼявляються** в 2024;
- [ ] «вливання», «інфузія» знаходять каталог, назва запису — сам запис;
- [ ] гейт: кількість записів категорії в індексі дорівнює `getAllInfusions().length`, бачено
      червоним на підміні джерела;
- [ ] іконка рядка — та сама, що в каталозі: `searchVisuals.ts` дістає гілку
      `getInfusionVisual(targetType)`, а не типовий `BookOpen`;
- [ ] клікнуто в Chromium: `Cmd+K` → «Покращена зброя» → сторінка запису, 200.

## Зроблено 2026-09-18

Колектор `collectInfusionItems` у `omniSearchData.ts` — 66 рядків лише в 2014, `href`
`/infusions/<slug>`, бейдж «Рівень N», `keywords`: джерело кодом і назвою книги
(`findSourceLabel`), `targetType` сирим і через `infusionTargetTranslations`, «вливання»,
«інфузія», «infusion». `visualKey = targetType`, `searchVisuals.ts` веде в
`getInfusionVisual`. Аліаси каталогу в `search-aliases.json`: «інфузія», «інфузії», «інфузії
винахідника», «вливання артифайсера» (K1-c: транслітерація; «вливання» — підрядок назви
каталогу, K2).

Гейт у `tests/content/omni-search-catalog-coverage.test.ts`: кількість = `getAllInfusions().length`,
у 2024 нуль, «вливання»/«інфузія»/«інфузії» знаходять рядок каталогу, «Покращена зброя» →
`/infusions/enhanced-weapon` першим, іконка = `getInfusionVisual(targetType)`. Бачено червоним
на `slice(1)` джерела. Плитка й таб — із реєстру (KR36.1), у 2024 їх немає.

Клікнуто в Chromium: `tests/e2e/omni-search.spec.ts` — «Покращена зброя» → сторінка запису, 200.
