# Правило унікальності візуальних ассетів (Visual Assets Uniqueness)

При додаванні будь-якої нової категорії, розділу, каталогу чи сутності на платформі, яка використовує широкоформатні зображення (16:9, банери, картки розділів):

1. **Заборонено перевикористовувати старі зображення**:
   - Не можна брати одну й ту саму картинку для двох різних категорій (наприклад, не використовувати `ancient_rules_tome.webp` одночасно для Заклинань і Довідника правил, чи `occult_alchemy_workbench.webp` одночасно для Викликів і Правил Майстра).
   - Кожна категорія та сутність повинна мати власне унікальне зображення у `public/images/categories/` або відповідній підпапці.

2. **Обов'язкова фіксація промптів для генерації**:
   - При створенні нової категорії обов'язково формується окремий запис у `prompts/todo/` або `prompts/done/done promts.md`.
   - Запис обов'язково містить:
     - **Назва сутності/категорії** (українською та англійською).
     - **Шлях до файлу** (наприклад, `/images/categories/rules_gamemaster_screen.webp`).
     - **Сюжет та опис сцени**.
     - **Промпт для генерації** (Cinematic 8k photorealistic D&D illustration, 16:9 aspect ratio, Unreal Engine 5 render, high fantasy/dark fantasy lighting).

3. **Розширення бібліотеки ассетів**:
   - Поповнювати бібліотеку зображень новими файлами без дублювання, підтримуючи єдиний кінематографічний 16:9 стиль платформи.
