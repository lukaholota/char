# Робочі терміни — Паладин Клятви корони (2014)

- Oath of the Crown → «Клятва корони»; назви пʼяти умінь підкласу взято дослівно з порівняльної сторінки.
- Defender (роль) → танк; Divine Smite → «Божественна кара»; Channel Divinity → «Канал божественності»; spell slot → слот заклинання.
- Eldritch Adept → «Містичний адепт»; Dwarven Fortitude → «Дворфська стійкість»; Mounted Combatant → «Верховий боєць»; Tough → «Здоровань» — форми зі словника/погоджених термінів.
- Insight → «Аналіз поведінки»; Persuasion → «Переконання»; Eldritch Invocations → «потойбічні виклики».
- Bugbear → Ведмебай; Hill Dwarf → Пагорбовий дворф — робоча форма з маркером оригіналу.
- Metagame shenanigans → «метагеймові хитрощі»{{metagame shenanigans}} — описовий робочий варіант у межах жарту джерела.
