Нумеровані продовження вже включених статей. `crawl-pagination.py` знаходить
посилання `/2/`, `/3/` у локальному HTML, а `--apply` зберігає перевірені повні
HTML та `.record.json` з `parentSourceId`. Повторний запуск відновлюється із
`source-pagination.json`; source ID батьківської статті й manifest не змінюються.

Зараз тут є сторінка 2 гайда Hobgoblin 2014. `coverage.ts` перевіряє її hash,
додає 7 секцій і 111 слів до батьківського запису та позначає
`pagination-supplement-review`. Переклад повинен містити обидві частини;
одна лише основна staging-ревізія цього змісту не містить.
